# Trilayer split of `codep-category`: structure / axioms / bundle

Validation spike for the trilayer restructure of `codep-category`,
motivated by the W1 termination finding: a multi-object direct
instance's `idn` cases on the object, so `idn y` at the variable
middle object of `compose-contr` stays stuck in the proof term — and
because the derived `_·_` lived in the *same* record as
`compose-contr`, that stuck `idn` was a self-call the termination
checker rejects.

The fix is to stratify:

1. **`codep-structure ob`** — hom/idn/emb + every axiom-free derived op.
2. **`codep-axioms (S : codep-structure ob)`** — `compose-contr` over
   `S`'s ops, plus the extraction and laws. Its proof references the
   *external* value `S`, never itself — the reason the rake becomes
   constructible.
3. **`codep-category (o h : Level)`** — the fully bundled object with
   fields `ob`, `structure`, `axioms`, re-exporting the other two.

## Layer 1 — `codep-structure`: hom/idn/emb and every axiom-free op

```agda
record codep-structure {o h} (ob : Type o) : Type (o ⊔ h ₊) where
  no-eta-equality
  field
    hom : ob → ob → Type h
    idn : (x : ob) → hom x x

  binder : ob → Type (o ⊔ h)
  binder x = Σ w ∶ ob , hom w x

  unit : (y : ob) → binder y
  unit y = y , idn y

  pass : ob → Type (o ⊔ h)
  pass x = ob × binder x

  fam : ∀ {x} → pass x → Type h
  fam (v , w , a) = hom w v

  at : ∀ {x} → (y : ob) → pass x → pass y
  at y φ = φ .fst , unit y

  acted : ∀ {x} → pass x → ob → Type h
  acted φ z = fam (at z φ)

  ctx : ob → ob → Type (o ⊔ h)
  ctx x y = Σ φ ∶ pass x , acted φ y

  composite : ob → ob → Type (o ⊔ h)
  composite x y = (γ : ctx x y) → fam (γ .fst)

  composite-ext : ∀ {x y} {F G : composite x y} → (∀ γ → F γ ≡ G γ) → F ≡ G
  composite-ext h = funext h

  field
    emb : ∀ {x y} → hom x y → composite x y

  is-representable : ∀ {x y} → composite x y → Type (o ⊔ h)
  is-representable F = fiber emb F

  act : ∀ {x} (φ : pass x) {y z} → hom y z → acted φ z → acted φ y
  act φ {y} g α = emb g (at y φ , α)

  sub : ∀ {x y z} → hom y z → ctx x z → ctx x y
  sub g (φ , α) = φ , act φ g α

  _·_ : ∀ {x y z} → composite x y → hom y z → composite x z
  (F · g) γ = F (sub g γ)
  infixl 30 _·_

  hom≃representable
    : ∀ {x y} → hom x y ≃ (Σ F ∶ composite x y , is-representable F)
  hom≃representable {x} {y} = iso→equiv fwd bwd hom-ret rep-sec
    where
      fwd : hom x y → Σ F ∶ composite x y , is-representable F
      fwd f = emb f , (f , refl)

      bwd : (Σ F ∶ composite x y , is-representable F) → hom x y
      bwd (F , a , p) = a

      hom-ret : ∀ f → bwd (fwd f) ≡ f
      hom-ret f = refl

      rep-sec : ∀ s → fwd (bwd s) ≡ s
      rep-sec (F , a , p) = J (λ F' p' → fwd a ≡ (F' , a , p')) refl p

  at-idem : ∀ {x} (φ : pass x) (y z : ob) → at z (at y φ) ≡ at z φ
  at-idem φ y z = refl
```

## Layer 2 — `codep-axioms`: `compose-contr` over an external structure

```agda
record codep-axioms {o h} {ob : Type o}
  (S : codep-structure {o} {h} ob) : Type (o ⊔ h) where
  no-eta-equality
  open codep-structure S

  field
    compose-contr
      : ∀ {x y z} (f : hom x y) (g : hom y z)
      → is-contr (is-representable (emb f · g))

  _⨾_ : ∀ {x y z} → hom x y → hom y z → hom x z
  f ⨾ g = compose-contr f g .center .fst
  infixr 40 _⨾_

  emb-comp : ∀ {x y z} (f : hom x y) (g : hom y z)
           → emb (f ⨾ g) ≡ emb f · g
  emb-comp f g = compose-contr f g .center .snd

  act-comp
    : ∀ {x} (φ : pass x) {y z w}
      (g : hom y z) (h : hom z w) (α : acted φ w)
    → act φ (g ⨾ h) α ≡ act φ g (act φ h α)
  act-comp φ {y} g h α = happly (emb-comp g h) (at y φ , α)

  sub-comp : ∀ {x y z w} (g : hom y z) (h : hom z w)
           → sub {x} (g ⨾ h) ≡ sub g ∘ sub h
  sub-comp g h = funext λ γ → ap (γ .fst ,_) (act-comp (γ .fst) g h (γ .snd))

  ·-comp : ∀ {x y z w} (F : composite x y) (g : hom y z) (h : hom z w)
         → F · (g ⨾ h) ≡ F · g · h
  ·-comp F g h = funext λ γ → ap F (happly (sub-comp g h) γ)
```

## Layer 3 — `codep-category`: the fully bundled object

`ob` is a field, the levels are parameters. The two `open … public`
lines re-export the whole structure + axioms namespace through the
bundle, so a single `open codep-category C` recovers exactly the
current API (hom, emb, composite, `_·_`, compose-contr, `_⨾_`, …).

```agda
record codep-category (o h : Level) : Type ((o ⊔ h) ₊) where
  no-eta-equality
  field
    ob        : Type o
    structure : codep-structure {o} {h} ob
    axioms    : codep-axioms structure
  open codep-structure structure public
  open codep-axioms axioms public
```

## Acceptance 1 — THE WALKING ARROW, DIRECT

The exact multi-object thin instance that tripped termination before,
written naively: a closed `codep-structure` value, the axioms over it,
then the bundle. No workaround, no top-level carrier gymnastics, no
`TypeInstance`.

```agda
module WalkArrow where
  data Ob : Type where
    o0 o1 : Ob

  homW : Ob → Ob → Type
  homW o0 o0 = ⊤
  homW o0 o1 = ⊤
  homW o1 o0 = ⊥
  homW o1 o1 = ⊤

  absurd : ∀ {u} {A : Type u} → ⊥ → A
  absurd ()

  comp3 : ∀ {w x y v} → homW w x → homW x y → homW y v → homW w v
  comp3 {w = o0} {v = o0}                   _ _ _ = tt
  comp3 {w = o0} {v = o1}                   _ _ _ = tt
  comp3 {w = o1} {v = o1}                   _ _ _ = tt
  comp3 {w = o1} {x = o0} {v = o0}          a _ _ = absurd a
  comp3 {w = o1} {x = o1} {y = o0} {v = o0} _ f _ = absurd f
  comp3 {w = o1} {x = o1} {y = o1} {v = o0} _ _ b = absurd b

  transW : ∀ {x y z} → homW x y → homW y z → homW x z
  transW {x = o0} {z = o0}          _ _ = tt
  transW {x = o0} {z = o1}          _ _ = tt
  transW {x = o1} {z = o1}          _ _ = tt
  transW {x = o1} {y = o0} {z = o0} a _ = absurd a
  transW {x = o1} {y = o1} {z = o0} _ b = absurd b

  hom-prop : (x y : Ob) → is-prop (homW x y)
  hom-prop o0 o0 = λ _ _ → refl
  hom-prop o0 o1 = λ _ _ → refl
  hom-prop o1 o0 = λ e _ → absurd e
  hom-prop o1 o1 = λ _ _ → refl

  WalkStructure : codep-structure Ob
  WalkStructure .codep-structure.hom = homW
  WalkStructure .codep-structure.idn o0 = tt
  WalkStructure .codep-structure.idn o1 = tt
  WalkStructure .codep-structure.emb f ((_ , (_ , a)) , b) = comp3 a f b

  open codep-structure WalkStructure

  WalkAxioms : codep-axioms WalkStructure
  WalkAxioms .codep-axioms.compose-contr {x} {_} {z} f g =
    prop-inhabited→is-contr fib-prop pt
    where
      comp-set : is-set (composite x z)
      comp-set = Π-is-set (λ _ → is-prop→is-set (hom-prop _ _))

      emb-inj : ∀ {h h'} → emb h ≡ emb h' → h ≡ h'
      emb-inj {h} {h'} _ = hom-prop x z h h'

      fib-prop : is-prop (fiber emb _)
      fib-prop = injective→is-embedding comp-set emb emb-inj _

      comp-prop : is-prop (composite x z)
      comp-prop F G = funext (λ γ → hom-prop _ _ (F γ) (G γ))

      pt : fiber emb _
      pt = transW f g , comp-prop _ _

  WalkCat : codep-category 0ℓ 0ℓ
  WalkCat .codep-category.ob = Ob
  WalkCat .codep-category.structure = WalkStructure
  WalkCat .codep-category.axioms = WalkAxioms
```

## Acceptance 2 — thin `emb` is an equivalence (the missing 2×2 cell)

Now that a multi-object thin instance is expressible, its `emb` is an
equivalence: `composite` is a Π into propositions, so every fibre is a
proposition, and evaluation at the canonical context
`((y,(x, idn x)), idn y)` inhabits it. This is the non-groupoid +
`emb`-equivalence square the conservativity spike could not reach.

```agda
  private
    comp-prop : ∀ {x y} → is-prop (composite x y)
    comp-prop F G = funext (λ γ → hom-prop _ _ (F γ) (G γ))

  emb-is-equiv : ∀ {x y} → is-equiv (emb {x} {y})
  emb-is-equiv {x} {y} .eqv-fibers F =
    prop-inhabited→is-contr fib-prop (F γ⋆ , comp-prop _ _)
    where
      γ⋆ : ctx x y
      γ⋆ = (y , (x , idn x)) , idn y

      emb-inj : ∀ {h h'} → emb h ≡ emb h' → h ≡ h'
      emb-inj {h} {h'} _ = hom-prop x y h h'

      fib-prop : is-prop (fiber emb F)
      fib-prop =
        injective→is-embedding
          (Π-is-set (λ _ → is-prop→is-set (hom-prop _ _))) emb emb-inj F
```

## Acceptance 3 — the coupling stack over the trilayer

The coupling *fields* (`interchange`, `post-eval`) use only `emb`,
`pre`, `post`, `idn` — all structure-level — so `codep-coupling` sits
over `codep-structure`. Only `CouplingDerived` needs the axioms
(`_⨾_`, `emb-comp`, `act-comp`). The `idem` module boundary survives:
`CouplingDerived` never opens the unit layer, so `idem` is derived
absorption-free, exactly as before.

```agda
module Coupling where
  module Helpers {o h} {ob : Type o} (S : codep-structure {o} {h} ob) where
    open codep-structure S

    pre : ∀ {y z} (g : hom y z) {v} → hom z v → hom y v
    pre {y} g {v} b = emb g ((v , (y , idn y)) , b)

    post : ∀ {x y} (f : hom x y) {w} → hom w x → hom w y
    post {x} {y} f {w} a = emb f ((y , (w , a)) , idn y)

  record codep-coupling {o h} {ob : Type o}
    (S : codep-structure {o} {h} ob) : Type (o ⊔ h) where
    no-eta-equality
    open codep-structure S
    open Helpers S
    field
      interchange
        : ∀ {x y z} (f : hom x y) (g : hom y z)
          {w} (a : hom w x) {v} (b : hom z v)
        → emb f ((v , (w , a)) , pre g b)
        ≡ emb g ((v , (w , post f a)) , b)
      post-eval
        : ∀ {x y} (f : hom x y) → post f (idn x) ≡ f

  module CouplingDerived {o h} {ob : Type o} {S : codep-structure {o} {h} ob}
    (A : codep-axioms S) (Coup : codep-coupling S) where
    open codep-structure S
    open codep-axioms A
    open Helpers S
    open codep-coupling Coup

    post-comp
      : ∀ {x y z} (f : hom x y) (g : hom y z) {w} (a : hom w x)
      → post (f ⨾ g) a ≡ post g (post f a)
    post-comp f g {w} a =
      happly (emb-comp f g) ((_ , (w , a)) , idn _)
      ∙ interchange f g a (idn _)

    comp-eq : ∀ {x y z} (f : hom x y) (g : hom y z) → f ⨾ g ≡ post g f
    comp-eq f g =
      sym (post-eval (f ⨾ g))
      ∙ post-comp f g (idn _)
      ∙ ap (λ t → post g t) (post-eval f)

    post-idpt : ∀ {x} → post (idn x) (idn x) ≡ idn x
    post-idpt = post-eval (idn _)

    idem : ∀ {x} → idn x ⨾ idn x ≡ idn x
    idem = comp-eq (idn _) (idn _) ∙ post-idpt

    pre-comp
      : ∀ {y z w} (g : hom y z) (h : hom z w) {v} (b : hom w v)
      → pre (g ⨾ h) b ≡ pre g (pre h b)
    pre-comp {y} g h b = act-comp (_ , unit y) g h b
```

## Representative Coherence — E₃ / `assoc` over the axioms layer

The pentagon tower's foundation ports unchanged: `Derived` opens both
records and the bodies are verbatim.

```agda
module Derived {o h} {ob : Type o} {S : codep-structure {o} {h} ob}
  (A : codep-axioms S) where
  open codep-structure S
  open codep-axioms A

  E₃ : ∀ {x y z w} (f : hom x y) (g : hom y z) (h : hom z w) → composite x w
  E₃ f g h = emb f · g · h

  E₃-contr : ∀ {x y z w} (f : hom x y) (g : hom y z) (h : hom z w)
           → is-contr (fiber emb (E₃ f g h))
  E₃-contr f g h .center =
    (f ⨾ g) ⨾ h , emb-comp (f ⨾ g) h ∙ ap (_· h) (emb-comp f g)
  E₃-contr f g h .paths =
    is-contr→is-prop
      (subst (λ T → is-contr (fiber emb T))
        (ap (_· h) (emb-comp f g))
        (compose-contr (f ⨾ g) h)) _

  assoc-σ : ∀ {x y z w} (f : hom x y) (g : hom y z) (h : hom z w)
          → E₃-contr f g h .center
          ≡ (f ⨾ (g ⨾ h) , emb-comp f (g ⨾ h) ∙ ·-comp (emb f) g h)
  assoc-σ f g h = is-contr→is-prop (E₃-contr f g h) _ _

  assoc : ∀ {x y z w} (f : hom x y) (g : hom y z) (h : hom z w)
        → (f ⨾ g) ⨾ h ≡ f ⨾ (g ⨾ h)
  assoc f g h = ap fst (assoc-σ f g h)
```

## Acceptance 5 — definitional behaviour preserved

`at-idem` refl and `composite` genuine Π now live in the structure
record itself; `act-comp` is still definitionally `happly` of
`emb-comp`.

```agda
module _ {o h} {ob : Type o} (S : codep-structure {o} {h} ob) where
  open codep-structure S

  -- `composite` is a genuine Π — application computes, no wrapper.
  composite-is-Π : ∀ {x y} (F : composite x y) (γ : ctx x y) → fam (γ .fst)
  composite-is-Π F γ = F γ

  -- Re-anchoring stays definitionally idempotent (as a field-record def).
  _ : ∀ {x} (φ : pass x) (y z : ob) → at z (at y φ) ≡ at z φ
  _ = at-idem

module _ {o h} {ob : Type o} {S : codep-structure {o} {h} ob}
  (A : codep-axioms S) where
  open codep-structure S
  open codep-axioms A

  -- `act-comp` is still definitionally `happly` of `emb-comp`.
  act-comp-is-happly
    : ∀ {x} (φ : pass x) {y z w}
      (g : hom y z) (hh : hom z w) (α : acted φ w)
    → act-comp φ g hh α ≡ happly (emb-comp g hh) (at y φ , α)
  act-comp-is-happly φ g hh α = refl
```

## Acceptance 4 — `Type-codep` ports mechanically over the trilayer

The committed instance splits into `Type-structure`, `Type-axioms`,
and the `Type-cat` bundle. The `compose-contr` `.center`/`.paths`
bodies are verbatim from `Cat.Codep.Instances`.

```agda
module TypeInstance {o h} (C : category o h) where
  private module C = Virtual C

  CompositeT : C.ob → C.ob → Type (o ⊔ h)
  CompositeT x y =
    (γ : Σ φ ∶ (Σ v ∶ C.ob , (Σ w ∶ C.ob , C.hom w x)) , C.hom y (φ .fst))
    → C.hom (γ .fst .snd .fst) (γ .fst .fst)

  uncurryT : ∀ {x y}
    → (∀ w → C.hom w x → ∀ v → C.hom y v → C.hom w v)
    → CompositeT x y
  uncurryT G γ =
    G (γ .fst .snd .fst) (γ .fst .snd .snd) (γ .fst .fst) (γ .snd)

  curryT : ∀ {x y}
    → CompositeT x y
    → (∀ w → C.hom w x → ∀ v → C.hom y v → C.hom w v)
  curryT F w a v b = F ((v , (w , a)) , b)

  Type-structure : codep-structure {o} {h} C.ob
  Type-structure .codep-structure.hom = C.hom
  Type-structure .codep-structure.idn x = C.idn
  Type-structure .codep-structure.emb f = uncurryT (C.emb f)

  Type-axioms : codep-axioms Type-structure
  Type-axioms .codep-axioms.compose-contr f g .center =
    (f C.⨾ g) , ap uncurryT (C.compose-contr f g .center .snd)
  Type-axioms .codep-axioms.compose-contr f g .paths (s , q) i =
    let p = C.compose-contr f g .paths (s , ap curryT q) i
    in p .fst , ap uncurryT (p .snd)

  Type-cat : codep-category o h
  Type-cat .codep-category.ob = C.ob
  Type-cat .codep-category.structure = Type-structure
  Type-cat .codep-category.axioms = Type-axioms
```
