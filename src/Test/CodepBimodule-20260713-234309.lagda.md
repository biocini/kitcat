## B1 — the bimodule record (memo §2.1)

A `C`-`C`-bimodule (a profunctor `C ⇸ C`) over an hcategory: a
bi-indexed carrier `F` with a left action `_⊳_` and a right action
`_⊲_` of the category's arrows, satisfying two unit laws, two
action-associativity laws, and the middle-interchange law. Both actions
are native fields (Decision 2 = (ii)); `interchange` is NOT a field. The
five laws are the strict (h ≤ 1) part; the three Kelly cells are the
wild residue and live in the `Cat.Codep.Coherent` overlay, not here.

```agda
record bimodule {o h} (C : hcategory o h) (fℓ : Level)
  : Type (o ⊔ h ⊔ fℓ ₊) where
  no-eta-equality
  open hcategory C
  field
    F   : ob → ob → Type fℓ
    _⊳_ : ∀ {w x y} → hom w x → F x y → F w y
    _⊲_ : ∀ {x y v} → F x y → hom y v → F x v
    ⊳-idn   : ∀ {x y} (p : F x y)
            → idn x ⊳ p ≡ p
    ⊲-idn   : ∀ {x y} (p : F x y)
            → p ⊲ idn y ≡ p
    ⊳-assoc : ∀ {w' w x y} (a' : hom w' w) (a : hom w x) (p : F x y)
            → (a' ⨾ a) ⊳ p ≡ a' ⊳ (a ⊳ p)
    ⊲-assoc : ∀ {x y v v'} (p : F x y) (b : hom y v) (b' : hom v v')
            → p ⊲ (b ⨾ b') ≡ (p ⊲ b) ⊲ b'
    middle  : ∀ {w x y v} (a : hom w x) (p : F x y) (b : hom y v)
            → (a ⊳ p) ⊲ b ≡ a ⊳ (p ⊲ b)
```

### The internal-hom left action (memo §3.1, SPIKE-LOCAL)

The right action on composites `_·_` is Base-native. The left action
`_⟩_` is not in Base; the spike supplies it directly over Base's `post`
— the cofamily reindex `_▹_` and `subl` mirror the faithful stratum's
`_⟩_`/`subl` (`Test.CodepFaithful…:132,163`), the codependent
cofamily-arrow action — cf. Petrakis's codependent side
(`Cat.Type` carrier vocabulary; Petrakis, arXiv:2303.14754, §6).
`_·_` touches the family (fam) slot, `_⟩_` the cofamily (cofam) slot —
disjoint, which is why interchange-1 is definitional.

```agda
  _▹_ : ∀ {w x} → cofam w → hom w x → cofam x
  c ▹ a = c .fst , post a (c .snd)

  subl : ∀ {w x y} → hom w x → ctx w y → ctx x y
  subl a (c , φ) = (c ▹ a) , φ

  _⟩_ : ∀ {w x y} → hom w x → composite x y → composite w y
  (a ⟩ F) γ = F (subl a γ)
  infixr 30 _⟩_
```

### R — the regular (Cayley) filling (memo §2.2)

The category acts on itself by composition: `F := hom`, `⊳ := ⨾`,
`⊲ := ⨾`. Every law is a category law already proven —
`unitl`/`unitr`/`assoc` (the `assoc` orientation matches `⊳-assoc`,
`middle`; `⊲-assoc` is `assoc` reversed, hence `sym`).

```agda
  R : bimodule C h
  R .bimodule.F   = hom
  R .bimodule._⊳_ = _⨾_
  R .bimodule._⊲_ = _⨾_
  R .bimodule.⊳-idn   p       = unitl p
  R .bimodule.⊲-idn   p       = unitr p
  R .bimodule.⊳-assoc a' a p  = assoc a' a p
  R .bimodule.⊲-assoc p b b'  = sym (assoc p b b')
  R .bimodule.middle  a p b   = assoc a p b
```

### H — the internal-hom bimodule (memo §3.1)

`F := composite`, `⊲ := _·_` (family/right, Base-native), `⊳ := _⟩_`
(cofamily/left, spike-local). Its `middle` = interchange-1 =
DEFINITIONAL (the two actions touch disjoint slots), pinned
`killcheck-itc1`. The unit/assoc laws hold by the family and cofamily
functoriality — `·-idn`/`·-comp` on the right, `absorb-r`/`post-comp`
(the cofamily mirror) on the left.

```agda
  H : bimodule C (o ⊔ h)
  H .bimodule.F   = composite
  H .bimodule._⊳_ = _⟩_
  H .bimodule._⊲_ = _·_
  H .bimodule.⊳-idn F = funext λ γ →
    ap (λ c → F (c , γ .snd)) (ap (γ .fst .fst ,_) (absorb-r (γ .fst .snd)))
  H .bimodule.⊲-idn F = ·-idn F
  H .bimodule.⊳-assoc a' a F = funext λ γ →
    ap (λ c → F (c , γ .snd))
      (ap (γ .fst .fst ,_) (post-comp a' a (γ .fst .snd)))
  H .bimodule.⊲-assoc F b b' = ·-comp F b b'
  H .bimodule.middle a F b = refl

  killcheck-itc1
    : ∀ {w x y v} (a : hom w x) (F : composite x y) (b : hom y v)
    → (a ⟩ F) · b ≡ a ⟩ (F · b)
  killcheck-itc1 a F b = refl
```

### B2 — emb as a bimodule hom R → H (memo §3.2, THE CRUX)

`emb` intertwines the two actions. Right-equivariance is `emb-comp`
verbatim; left-equivariance `emb-⊳` is the A2 wall over the abstract
stratum, but DERIVES over β.

Right-equivariance (FREE): under `⊲_R := ⨾`, `emb (f ⊲ b) ≡ emb f · b`
is `emb (f ⨾ b) ≡ emb f · b` = `emb-comp f b` (Base:291), VERIFIED. No
new definition — a wrapper of `emb-comp` would be beta-eta-redundant, so
it is stated, not re-typed.

Left-equivariance (the crux): under `⊳_R := ⨾`, `emb (a ⊳ f) ≡ a ⟩ emb f`
is `emb (a ⨾ f) ≡ a ⟩ emb f`. The β route (§3.2): `emb-comp`, then
`op-comp-path` (which is `funext` of one `interchange` — the injected
field), then the op-transpose link. That final link is DEFINITIONAL:
`op-comp-path`'s funext-of-interchange term inhabits both
`emb a · f ≡ swap·' (embᵒ f ·ᵒ a)` and `emb a · f ≡ a ⟩ emb f`, because
`swap·' (embᵒ f ·ᵒ a) = λ γ → emb f (swap (subᵒ a (swap γ))) =
λ γ → emb f (subl a γ) = a ⟩ emb f` reduces (via `preᵒ = post` and Σ
eta). So the ternary chain closes with `refl` at the third link.

```agda
  emb-⊳ : ∀ {w x y} (a : hom w x) (f : hom x y) → emb (a ⨾ f) ≡ a ⟩ emb f
  emb-⊳ a f =
    pcom (sym (emb-comp a f)) (op-comp-path axioms f a) refl
```

The §3.3 pointwise formula `emb f ((w,a),(v,b)) ≡ (a ⊳ f) ⊲ b`, in the

### B3 — emb-parity (memo §4, thin)

The op/parity story: under op the two representable actions SWAP
(definitionally), `emb` transposes (definitionally), and the centre
Kelly cell is op-fixed. The action-swap and emb-transpose are pinned by
`refl`; `emb-parity` is B2's `pointwise` at the swapped (op) context.

```agda

                 → Sᵒ.pre g b ≡ post g b
  killcheck-preᵒ g b = refl

  killcheck-postᵒ : ∀ {x y w} (f : hom y x) (a : hom x w)
                  → Sᵒ.post f a ≡ pre f a
  killcheck-postᵒ f a = refl

                 → Sᵒ.emb f ≡ swap· structure (emb f)
```
