## (2) The memo's definitional claims

(2a) op's free law at the identity IS the base coupling law: `happly`
distributes over `∙` definitionally, `happly ∘ funext = id`, and
`swap ∘ swap = id`, so `Aᵒᴮ.pre-comp` (= `Sᵒ.pre`-comp = `S.post`-comp)
at the identity is literally `A.post-comp`.

```agda
  pre-compᵒ-is-post-comp
    : ∀ {w x} (c : S.hom w x)
    → Aᵒᴮ.pre-comp (Sᵒ.idn x) (Sᵒ.idn x) c
    ≡ A.post-comp (S.idn x) (S.idn x) c
  pre-compᵒ-is-post-comp c = refl
```

(2b) The mirror side: `Aᵒᴮ.post-comp` at the identity carries the
op's extra interchange twice (once from `op-comp-path` inside the
Route-B `emb-comp`, once from `icᵒ = sym interchange`), and the two
occurrences ARE the same term, so a single `Path.invr` collapses it
onto the base `pre-comp`.

```agda
  post-compᵒ-is-pre-comp
    : ∀ {x v} (c : S.hom x v)
    → Aᵒᴮ.post-comp (Sᵒ.idn x) (Sᵒ.idn x) c
    ≡ A.pre-comp (S.idn x) (S.idn x) c
  post-compᵒ-is-pre-comp {x} {v} c =
      sym (Path.assoc H IC' (sym IC'))
    ∙ ap (H ∙_) (Path.invr IC')
    ∙ Path.unitr H
    where
      H = A.pre-comp (S.idn x) (S.idn x) c
      IC' = A.interchange (S.idn x) (S.idn x) (S.idn x) c
```

## (3) θ — the milestone

`Aᵒᴮ.idem` and `A.idem` share type (Route-B: `⨾ᵒ (idn)(idn) =
A._⨾_ (idn)(idn)` definitionally, `Sᵒ.idn = S.idn`), and both unfold
to `comp-eq (idn)(idn) ∙ post-eval (idn)`. The two `comp-eq`s share
the leading `sym (post-eval (idn⨾idn))` and the trailing `post-eval`;
their middle-tails differ, and reconcile — after the `Path.invr`
collapse of the doubled interchange (`κ`) — through the single
irreducible cell θ-core.
