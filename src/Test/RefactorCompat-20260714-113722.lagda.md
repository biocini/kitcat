## G1 — the `emb` curry/uncurry round-trip is definitional

Mirrors `Cat.Codep.Instances.type-instance` (`Instances:160-186`)
exactly: `Cat.Type`'s curried 4-ary `emb` view (`CurriedT`) against
`hcategory`'s uncurried composite view (`CompositeT`, a Π over
`ctx x y = cofam x × fam y`), with the same `uncurryT` / `curryT`
glue. The refactor's transplant leans on both round-trips reducing on
the nose. `curryT ∘ uncurryT = id` is beta + function eta;
`uncurryT ∘ curryT = id` additionally needs Σ eta (builtin `Sigma`
has it).

```agda
module curry-uncurry-killcheck {o h} (C : category o h) where
  private module C = Virtual C

  CurriedT : C.ob → C.ob → Type (o ⊔ h)
  CurriedT x y = ∀ w → C.hom w x → ∀ v → C.hom y v → C.hom w v

  CompositeT : C.ob → C.ob → Type (o ⊔ h)
  CompositeT x y =
    (γ : (Σ w ∶ C.ob , C.hom w x) × (Σ v ∶ C.ob , C.hom y v))
    → C.hom (γ .fst .fst) (γ .snd .fst)

  uncurryT : ∀ {x y} → CurriedT x y → CompositeT x y
  uncurryT G γ =
    G (γ .fst .fst) (γ .fst .snd) (γ .snd .fst) (γ .snd .snd)

  curryT : ∀ {x y} → CompositeT x y → CurriedT x y
  curryT F w a v b = F ((w , a) , (v , b))

  killcheck-curry-uncurry
    : ∀ {x y} (G : CurriedT x y) → curryT (uncurryT G) ≡ G
  killcheck-curry-uncurry G = refl

  killcheck-uncurry-curry
    : ∀ {x y} (F : CompositeT x y) → uncurryT (curryT F) ≡ F
  killcheck-uncurry-curry F = refl

  -- The bridge pinned at the actual `Cat.Type` embedding: the curried
  -- `emb f` recovers through the uncurried composite view on the nose.
  killcheck-emb-roundtrip
    : ∀ {x y} (f : C.hom x y) → curryT (uncurryT (C.emb f)) ≡ C.emb f
  killcheck-emb-roundtrip f = refl
```

## G2 — `cast-path` over `hcategory`

The `Cat.Base` composite-witness `_⨾_=>_ f g s = emb s ≡ (λ w a v b →
emb f w a v (noy g v b))` (`Base:37-47`) restates in the `hcategory`
composite idiom as `emb s ≡ emb f · g` — the RHS is exactly
`emb-comp`'s RHS (`Cat.Type:291`). The `is-representable
(emb f · g) = fiber emb (emb f · g)` fiber is `compose-contr f g`'s
carrier, so `cast-path = ap fst (compose-contr f g .paths (s , α))`
transplants verbatim; `cast-path⁻¹` is `ap emb (sym p) ∙ emb-comp f g`.

```agda
module cast-path-transplant {o h} (C : hcategory o h) where
  open hcategory C

  _⨾_=>_ : ∀ {x y z} → hom x y → hom y z → hom x z → Type (o ⊔ h)
  _⨾_=>_ {x} {y} {z} f g s = emb s ≡ emb f · g

  cast-path
    : ∀ {x y z} {f : hom x y} {g : hom y z} {s : hom x z}
    → f ⨾ g => s → f ⨾ g ≡ s
  cast-path {f = f} {g} {s} α =
    ap fst (compose-contr f g .paths (s , α))

  cast-path⁻¹
    : ∀ {x y z} {f : hom x y} {g : hom y z} {s : hom x z}
    → f ⨾ g ≡ s → f ⨾ g => s
  cast-path⁻¹ {f = f} {g} {s} p = ap emb (sym p) ∙ emb-comp f g

  -- The canonical witness `f ⨾ g => (f ⨾ g)` is exactly `emb-comp f g`,
  -- and `cast-path` of it is a self-identity in the contractible fiber.
  canonical-witness : ∀ {x y z} (f : hom x y) (g : hom y z) → f ⨾ g => (f ⨾ g)
  canonical-witness f g = emb-comp f g

  cast-path-canonical
    : ∀ {x y z} (f : hom x y) (g : hom y z)
    → f ⨾ g ≡ f ⨾ g
  cast-path-canonical f g = cast-path (canonical-witness f g)
```

## G3 — `Cat`-over-`hcategory`: towers + whiskering in scope

The transplant home for P2. Opening `assoc-tower` / `pentagon-tower` /
`triangle-weak-tower` (each gating only on `C : hcategory o h`) puts
`assoc`, the pentagon fibers, and the weak triangle in scope;
whiskering transplants verbatim as `ap (_⨾ h)` / `ap (h ⨾_)`. The small
consumer `whisker-assoc` combines `assoc` (from the tower) with the
right whisker, demonstrating both compose.

```agda
module Cat {o h} (C : hcategory o h) where
  open hcategory C
  open assoc-tower C
  open pentagon-tower C
  open triangle-weak-tower C

  _▹_ : ∀ {x y z} {f g : hom x y} → f ≡ g → (h' : hom y z)
      → f ⨾ h' ≡ g ⨾ h'
  p ▹ h' = ap (_⨾ h') p
  infixl 40 _▹_

  _◃_ : ∀ {x y z} (f : hom x y) {g h' : hom y z} → g ≡ h'
      → f ⨾ g ≡ f ⨾ h'
  f ◃ p = ap (f ⨾_) p
  infixr 40 _◃_

  -- assoc, from the tower, is directly in scope.
  assoc-in-scope
    : ∀ {x y z w} (f : hom x y) (g : hom y z) (h' : hom z w)
    → (f ⨾ g) ⨾ h' ≡ f ⨾ (g ⨾ h')
  assoc-in-scope = assoc

  -- the weak triangle, from the tower, is in scope.
  triangle-weak-in-scope
    : ∀ {x y z} (f : hom x y) (g : hom y z)
    → ap (_⨾ g) (unitr f)
    ≡ assoc f (idn y) g ∙ triangle-fibers.α₂₃ f g
  triangle-weak-in-scope = triangle-weak

  -- small consumer: right-whisker of assoc typechecks over the tower.
  whisker-assoc
    : ∀ {x y z w v}
      (f : hom x y) (g : hom y z) (h' : hom z w) (k : hom w v)
    → ((f ⨾ g) ⨾ h') ⨾ k ≡ (f ⨾ (g ⨾ h')) ⨾ k
  whisker-assoc f g h' k = assoc f g h' ▹ k
```

The pentagon fibers are reachable at a fixed quadruple (the same
access pattern `Instances:199-209` uses over `type-instance`).

```agda
  module _ {x y z w v}
    (f : hom x y) (g : hom y z) (h' : hom z w) (k : hom w v) where
    open pentagon-tower.pentagon-fibers C f g h' k
    _ = pentagon
```

The full triangle gates additionally on the coherence overlay
`A2 : hcategory-2-coherent C`; a small consumer over that parameter
shows `triangle-full-tower` opens and the full Mac Lane triangle is in
scope.

```agda
module Cat-coherent {o h} (C : hcategory o h)
  (A2 : hcategory-2-coherent C) where
  open hcategory C
  open assoc-tower C
  open triangle-full-tower C A2

  full-triangle-in-scope
    : ∀ {x y z} (f : hom x y) (g : hom y z)
    → ap (_⨾ g) (unitr f)
    ≡ assoc f (idn y) g ∙ ap (f ⨾_) (unitl g)
  full-triangle-in-scope f g = triangle-full.triangle f g
```

The op-dual (mirror) triangle is the free instantiation at
`(op C , op-coherent A2)`; opening `mirror-triangle` over the overlay
demonstrates that composition resolves (kept in its own module — its
public re-export of `triangle-full` would otherwise shadow
`Cat-coherent`'s).

```agda
module Cat-mirror {o h} {C : hcategory o h}
  (A2 : hcategory-2-coherent C) where
  open mirror-triangle A2
```
