# Curry–Howard, decidability, and elementary number theory

Operational reference for doing ordinary mathematics in Martin-Löf's
dependent type theory *before* propositional truncations are available:
the Curry–Howard interpretation of logic, the standard finite types
`Fin k` and modular arithmetic `ℤ/k`, decidability and decidable
equality, the well-ordering principle of `ℕ`, the greatest common
divisor, and the infinitude of primes. Digested from Rijke,
*Introduction to HoTT*, §"Modular arithmetic via the Curry–Howard
interpretation" and §"Decidability in
elementary number theory"; strong induction is
proved in the funext chapter and summarized here because it belongs to
the same toolkit. Prerequisites: dependent-type-theory.md,
inductive-types.md, identity-types.md, universes.md.

The one-sentence summary: logic is done with *general* types (Σ for ∃,
Π for ∀, + for ∨), and because excluded middle is unavailable, every
case split must be earned by *proving decidability* — which then buys
least-element search, the gcd, and primality testing, all as functions.

## Key definitions

### Curry–Howard (pre-truncation)

Propositions are types; proofs are elements; predicates are type
families. The translation table as used at this stage:

| Logic | Type theory |
|---|---|
| ⊤ | `𝟏` |
| ⊥ | `𝟘` |
| P ∨ Q | `A + B` |
| P ∧ Q | `A × B` |
| P ⇒ Q | `A → B` |
| ¬P | `A → 𝟘` |
| ∃ x. P(x) | `Σ (x:A). B x` |
| ∀ x. P(x) | `Π (x:A). B x` |
| x = y | `x = y` (identity type) |

Relations are *typal*: a binary relation on `A` is a family `R(x,y)`;
reflexivity/symmetry/transitivity are dependent functions; a typal
equivalence relation has all three.

- **Divisibility.** `d ∣ n := Σ (k:ℕ). d · k = n`. To *show* `d ∣ n`,
  give a pair `(k , p)`; to *use* `H : d ∣ n`, Σ-induct on `H` to get
  `k` and `p : d · k = n`. Proof-relevant: the quotient `k` is data.
- **Distance and congruence.** `dist : ℕ → ℕ → ℕ` by
  `dist(0,0) := 0`, `dist(0, y+1) := y+1`, `dist(x+1, 0) := x+1`,
  `dist(x+1, y+1) := dist(x, y)`. Then Gauss's definition:
  `x ≡ y mod k := k ∣ dist(x, y)` — an equivalence relation on `ℕ`.

Caveat (Rijke flags it): at this stage `Σ` serves double duty as both
"subset" `{x ∈ A ∣ P(x)}` and "there exists", and nothing enforces
proof irrelevance; the fix (`∃` via `‖Σ‖`) comes in logic-truncation.md.

### Standard finite types and the mod-k quotient map

- `Fin : ℕ → 𝒰` recursively: `Fin 0 := 𝟘`, `Fin (k+1) := Fin k + 𝟏`.
  Write `i : Fin k → Fin (k+1)` for `inl` and `⋆ : Fin (k+1)` for
  `inr ⋆`. Induction principle: the family is generated by `i` and `⋆`,
  so define/prove by pattern matching with clauses `f (i x) := … f x …`
  and `f ⋆ := …`; the clauses hold judgmentally.
- `nat-Fin : Fin k → ℕ` by `nat-Fin (i x) := nat-Fin x`,
  `nat-Fin ⋆ := k`. Bounded (`nat-Fin x < k`) and injective.
- Cyclic successor structure: `zero-Fin : Fin (k+1)` (index mismatch:
  `zero-Fin₀ := ⋆`, `zero-Fin_{k+1} := i (zero-Fin k)`);
  `skip-zero-Fin : Fin k → Fin (k+1)`; and `succ-Fin : Fin k → Fin k`
  by `succ-Fin (i x) := skip-zero-Fin x`, `succ-Fin ⋆ := zero-Fin`.
- **Quotient map** `[-]_{k+1} : ℕ → Fin (k+1)` by iteration:
  `[0] := 0`, `[x+1] := succ-Fin [x]`.
- **Split surjective**: `Π (b:B). Σ (a:A). f a = b` — Curry–Howard
  surjectivity, *stronger* than classical (explicit preimages).
- **Integers mod k**: `ℤ/0 := ℤ` and `ℤ/(k+1) := Fin (k+1)`.
  Addition `x + y := [nat-Fin x + nat-Fin y]_{k+1}`; inverse
  `-x := [dist(nat-Fin x, k+1)]_{k+1}`. (Multiplication, an exercise:
  `x · y := [nat-Fin x · nat-Fin y]_{k+1}`.)

### Decidability

- `is-decidable(A) := A + ¬A`. A family `P` over `A` is decidable if
  `Π (x:A). is-decidable(P x)`.
- `has-decidable-equality(A) := Π (x y:A). is-decidable(x = y)`.
- `booleanization : is-decidable(A) → bool` by `inl a ↦ true`,
  `inr f ↦ false`.
- Bounds for a family `P` over `ℕ`:
  `is-lower-bound_P(n) := Π (x:ℕ). P x → (n ≤ x)`;
  `is-upper-bound_P(n) := Π (x:ℕ). P x → (x ≤ n)`.
- **Gcd specification**:
  `is-gcd_{a,b}(d) := Π (x:ℕ). (x ∣ a) × (x ∣ b) ↔ (x ∣ d)`.
- Family for constructing the gcd by least-element search:
  `M(a,b,n) := (a + b ≠ 0) → (n ≠ 0) × Π (x:ℕ). (x ∣ a) × (x ∣ b) → (x ∣ n)`
  (nonzero common multiples of all common divisors; vacuous if
  `a + b = 0`).
- `is-proper-divisor(n,d) := (d ≠ n) × (d ∣ n)`;
  `is-prime(n) := Π (x:ℕ). is-proper-divisor(n,x) ↔ (x = 1)`.
- Family for Euclid's argument:
  `R(n,m) := (n < m) × Π (x:ℕ). (x ≤ n) → ((x ∣ m) → (x = 1))`
  ("m exceeds n and is relatively prime to every x ≤ n").

## Key results

### Curry–Howard in action

- Divisibility facts: `Π (x:ℕ). 1 ∣ x` (quotient `x`, left unit law);
  `k ∣ 0` (quotient `0`, right annihilation); `k ≡ 0 mod k`.
- **div-3-for-2**: if `d` divides any two of `x`, `y`, `x + y` it
  divides the third. Σ-induct on the hypotheses; build
  `d·(k+l) = d·k + d·l = x + d·l = x + y` from distributivity and two `ap`s.
- **Congruence is an equivalence relation.** Reflexivity:
  `dist(x,x) = 0`; symmetry: `dist(x,y) = dist(y,x)`; transitivity:
  of `dist(x,y)`, `dist(y,z)`, `dist(x,z)` two add to the third
  (case analysis on the six orderings of `x,y,z`), then div-3-for-2.
- **Effectiveness of the quotient map** (thm:effective-mod-k):
  `[x]_{k+1} = [y]_{k+1} ↔ x ≡ y mod (k+1)` — the engine of all mod-k
  reasoning. Chain: injectivity of `nat-Fin` reduces equality to
  `nat-Fin[x] = nat-Fin[y]`; both sides `< k+1`, so by the key lemma
  this is `nat-Fin[x] ≡ nat-Fin[y]`; and `nat-Fin[x] ≡ x mod (k+1)`
  by induction (prp:cong-nat-mod-succ).
- **Key lemma** (cor:eq-congN): for `x < d`, `d ∣ x ↔ x = 0`; hence
  for `dist(x,y) < k`, `x ≡ y mod k ↔ x = y`. Proof: from `d·k' = x+1`
  case-split on `k'`; `k' = 0` is contradictory, else `d ≤ d·k' = x+1`
  contradicts `x+1 < d`.
- **Split surjectivity** (thm:issec-nat-Fin): `[nat-Fin x]_{k+1} = x`;
  `nat-Fin` is a section of `[-]_{k+1}`.
- Computation lemmas: `nat-Fin zero-Fin = 0`;
  `nat-Fin (skip-zero-Fin x) = nat-Fin x + 1`;
  `nat-Fin (succ-Fin x) ≡ nat-Fin x + 1 mod k`;
  `nat-Fin[x]_{k+1} ≡ x mod (k+1)`.
- **ℤ/k is an abelian group.** Congruence respects `+` (any two of
  `x ≡ x'`, `y ≡ y'`, `x+y ≡ x'+y'` imply the third, via translation
  invariance `a ≡ b mod k ↔ a+c ≡ b+c mod k`); each group law on
  `ℤ/(k+1)` reduces via effectiveness to a congruence of `nat-Fin`
  values, proved from the computation lemmas and the ℕ-laws.

### Decidability

- `𝟏` and `𝟘` are decidable (`inl ⋆`, `inr id`); any *pointed* type is
  decidable. Principal moves: exhibit an element, or a map to `𝟘`.
- **Closure**: `A`, `B` decidable ⇒ `A + B`, `A × B`, `A → B`, `¬A`
  decidable. The construction reproduces the truth table, e.g.
  `A → B` from `inr f : ¬A` is `inl (ex-falso ∘ f)`; from `inl a` and
  `inr g : ¬B` is `inr (λh. g (h a))`.
- Decidable transfers across `↔`: `A ↔ B` gives
  `is-decidable(A) ↔ is-decidable(B)` (negation is contravariantly
  functorial; coproducts are functorial).
- `Eq-ℕ m n`, `m ≤ n`, `m < n` are decidable (induction; `Eq-ℕ`
  computes to `𝟏`/`𝟘`). Hence **ℕ has decidable equality** via
  `(m = n) ↔ Eq-ℕ m n`; **Fin k has decidable equality** via `Eq-Fin`;
  **ℤ too** (exercise: transport along `+`).
- **Divisibility is decidable** (thm:is-decidable-div-N):
  `0 ∣ x ↔ x = 0`; `(d+1) ∣ x ↔ [x]_{d+1} = 0` by effectiveness plus
  decidable equality of `Fin (d+1)`.
- **Improved arrow/product closure** (prp:is-decidable-function-type):
  if `A` is decidable and `A → is-decidable(B)`, then `A × B` and
  `A → B` are decidable (one point of `A` suffices to test).
- **Bounded Π is decidable** (prp:is-decidable-pi-type): for decidable
  `P` over `ℕ`, if `Π (x:ℕ). (m ≤ x) → P x` is decidable then
  `Π (x:ℕ). P x` is decidable — induction on `m`, peeling off `P 0`,
  shifting `P'(x) := P(x+1)`. Corollary: `P`, `Q` decidable and `P`
  upper-bounded ⇒ `Π (n:ℕ). P n → Q n` decidable. The workhorse for
  every "check finitely many cases" argument.
- **With-abstraction**: to define `f : Π (x:A). C x` using
  `g : Π (x:A). B x`, generalize `g x` to a free variable, define
  `h : Π (x:A). B x → C x`, set `f := λx. h x (g x)`. This makes case
  analysis on a *computed* decision type-correct; showcased by Collatz:
  `collatz n := h n (d n)` with `d : Π (n:ℕ). is-decidable(2 ∣ n)`,
  `h (n , inl (m,p)) := m`, `h (n , inr _) := 3n+1`.
- **Boolean reflection**: for `d : is-decidable(A)` there is
  `reflect : (booleanization d = true) → A`, built by pattern matching
  with `ex-falso ∘ γ` on the `inr` branch (`γ : (false = true) → 𝟘`).
  Offloads decisions to the computer: `reflect (d 37 , refl) : is-prime 37`
  typechecks because `d 37` *computes* to some `inl t`.

### Well-ordering, strong induction, gcd, primes

- **Well-ordering principle of ℕ** (thm:well-ordering-principle-N):
  for `P` decidable over `ℕ` (witnessed by `d`),
  `well-ordering-principle(P, d) : (Σ (n:ℕ). P n) → Σ (m:ℕ). P m × is-lower-bound_P(m)`.
  A *function*: from any witness it computes the least witness.
- **Strong induction** (thm:strong-ind-N, funext chapter): from
  `p₀ : P 0` and `pₛ : Π (n:ℕ). (Π (m:ℕ). (m ≤ n) → P m) → P (n+1)`,
  get `strong-ind-ℕ(p₀,pₛ) : Π (n:ℕ). P n`, with computation rules
  *as identifications* (funext is needed):
  `strong-ind-ℕ(p₀,pₛ,0) = p₀` and
  `strong-ind-ℕ(p₀,pₛ,n+1) = pₛ(n, λm. λp. strong-ind-ℕ(p₀,pₛ,m))`.
  Derived from ordinary induction on `P̃(n) := Π (m:ℕ). (m ≤ n) → P m`,
  specialized at `(n, n, refl≤)`.
- **Gcd exists and satisfies its specification.** Uniqueness: two gcds
  divide each other; `∣` is antisymmetric on `ℕ`. Construction:
  `M(a,b,·)` is decidable (bounded-Π: a common divisor of `a,b`
  divides `a+b`, so is `≤ a+b` when `a+b ≠ 0`); `M(a,b,a+b)` holds;
  well-ordering gives the least such `n` — that is `gcd(a,b)`.
  Lemma: `gcd(a,b) = 0 ↔ a + b = 0` (uses
  `¬¬(a+b = 0) → (a+b = 0)` from decidable equality of ℕ).
  Verification of the spec uses **Euclidean division** (an exercise,
  but load-bearing): `a = q·b + r` with `(b ≠ 0) → (r < b)`, uniquely.
  Divide `a` by `gcd(a,b)`; the remainder `r < gcd(a,b)` is divisible
  by every common divisor of `a, b` (div-3-for-2), so `r = 0` by
  minimality — hence `gcd(a,b) ∣ a`, and similarly `∣ b`.
- **`is-prime n` is decidable**: reformulate as
  `is-prime'(n) := (n ≠ 1) × Π (x:ℕ). is-proper-divisor(n,x) → (x = 1)`
  (interderivable); the Π is bounded since a proper divisor of
  `n ≠ 0` is `≤ n`; `n = 0` fails since every nonzero number properly
  divides `0`.
- **Infinitude of primes** (Euclid): for each `n` a prime `p > n`.
  `R(n,·)` is decidable; `R(n, n! + 1)` holds (any `x ≤ n` dividing
  `n!+1` also divides `n!`, hence `1`, so `x = 1`); well-ordering
  gives the least `m` with `R(n,m)`; that `m` is prime: a proper
  divisor `x` of `m` has `x < m`, so `¬R(n,x)` by minimality, yet the
  second component of `R(n,x)` holds by transitivity of `∣` — forcing
  `n ≮ x`, i.e. `x ≤ n`, and then `R(n,m)` yields `x = 1`.

## Reasoning idioms

- **Prove ∃ by pairing, use ∃ by Σ-induction.** Same shape for every
  Σ-defined concept (divisibility, split surjectivity). The witness is
  data — keep it, don't truncate it (yet).
- **To reason by cases, first prove decidability, then coproduct-induct
  on the decision.** The decision is usually *computed* (`d x`), not a
  free variable: generalize it to a free `y : is-decidable(P x)`
  (with-abstraction), pattern-match the helper on `inl`/`inr`, apply
  to `d x`.
- **Decidable equality via observational equality.** Define a
  type-valued relation by recursion computing to `𝟏`/`𝟘` (`Eq-ℕ`,
  `Eq-Fin`), show `(x = y) ↔ Eq x y`, transfer decidability across
  the `↔`. The standard two-step for every concrete inductive type.
- **Reduce mod-k equalities to ℕ congruences.** For an equation in
  `ℤ/(k+1)`, apply effectiveness and the section `[nat-Fin x] = x` to
  get `a ≡ b mod (k+1)`; compute with the `nat-Fin` lemmas and quote
  ℕ-laws. Never unfold `succ-Fin` iterations by hand.
- **Kill congruences below the modulus.** `x < d` turns `d ∣ x` into
  `x = 0` (cor:eq-congN) — Rijke's replacement for pigeonhole-style
  size arguments: bound everything by `k+1`, then congruence *is* equality.
- **Bound a Π-type to decide it.** To decide `Π (x:ℕ). P x → Q x`,
  exhibit an upper bound for `P` (divisors of `n ≠ 0` are `≤ n`) and
  apply cor:is-decidable-bounded-pi. Unbounded Π over ℕ is not
  decidable in general.
- **Strengthen the induction hypothesis by quantifying over a universe
  of families.** Both well-ordering and prp:is-decidable-pi-type prove
  `∀ Q : ℕ → 𝒰. …` by induction on the bound, using the shifted family
  `Q'(x) := Q(x+1)` in the step (enough-universes places `P` in `𝒰`).
- **Derive strong induction from ordinary induction on a bounded
  quantifier**: induct on `P̃(n) := Π (m:ℕ). (m ≤ n) → P m`, specialize
  at `m := n`. The same "bundle the ∀-below into the motive" move
  underlies the well-ordering proof.
- **Specify first, construct second.** `is-gcd_{a,b}(d)` pins down the
  gcd uniquely (mutual divisibility + antisymmetry), so any
  construction — well-ordering or Euclid's algorithm — is equally good.
- **Least-element search as a function.** Decidability of `P` plus one
  witness yields `Σ (m:ℕ). P m × is-lower-bound_P(m)` — no choice
  principle needed. (Counterpart: bounded decidable families with a
  witness have a *greatest* element — a second gcd construction.)
- **Double-negation elimination on decidable types only**:
  `is-decidable(A) → ¬¬A → A`; used to conclude `a + b = 0` from
  `¬(a+b ≠ 0)`.
- **Reflect to compute.** For a specific decidable fact
  (`is-prime 37`), hand the computer `reflect (d , refl)` and let
  judgmental equality evaluate the decision procedure.

## Pitfalls

- **No excluded middle.** `A + ¬A` is not available for arbitrary `A`;
  case analysis is a theorem to prove, not an axiom. Every case split
  in this chapter is backed by an explicit decidability proof.
- **Decidable ≠ true.** `is-decidable(A)` is a coproduct: you may be
  holding `inr f` with `f : ¬A`. Inspecting the constructor *is* the
  case split.
- **Curry–Howard is proof-relevant here.** `d ∣ n` contains the
  quotient; `Σ` conflates "subset" with "exists"; "split surjective"
  is stronger than surjectivity. Repaired later with `is-prop` and
  `‖−‖` (logic-truncation.md) — don't import that reading back.
- **Bounded decidability needs the bound up front.** You cannot decide
  `Π (x:ℕ). P x` for a general decidable `P`; the upper bound (or the
  hypothesis `Π (x:ℕ). (m ≤ x) → P x`) is an input, not a conclusion.
- **Index discipline on Fin.** `zero-Fin : Fin (k+1)` lives one index
  up; `[-]_{k+1}` and the group structure exist only on `Fin (k+1)`;
  `ℤ/0 := ℤ` (congruence mod 0 is equality), *not* `Fin 0 = 𝟘`.
- **The bounds in the key lemma are hypotheses.** `d ∣ x ↔ x = 0`
  requires `x < d`; dropping it "proves" nonsense mod k. Effectiveness
  is modulo `k+1`, matching `Fin (k+1)`.
- **Strong induction's computation rules are identifications, not
  judgmental**, and their proof uses function extensionality; rewriting
  with them needs transport, not definitional unfolding.
- **`¬¬A → A` only for decidable `A`.** The gcd proof leans on this;
  for arbitrary propositions it is (a weak form of) classical reasoning.
- **Boolean reflection hides the proof.** `reflect (d 37 , refl)` is a
  bona fide element of `is-prime 37` but carries no readable
  certificate; fine for computation, unacceptable as an explanation.
- **Antisymmetry of `∣` is special to ℕ** (on ℤ it holds only up to
  sign); uniqueness of the gcd rests on it.
