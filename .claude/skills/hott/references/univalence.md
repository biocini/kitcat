# The univalence axiom

The univalence axiom (Voevodsky) characterizes the identity type of a
universe: for types `A B : 𝒰` in a univalent universe,

    (A =_𝒰 B)  ≃  (A ≃ B)

It *expands* equality to encapsulate equivalence: equivalent types may
be identified, and every identification of types coerces to an
equivalence. This single axiom legitimizes the everyday habit of
identifying isomorphic objects — and it has sweeping consequences:
propositional extensionality (logically equivalent propositions are
equal), function extensionality (proved, not assumed), the object
classifier (type families over `A` are maps into `A`), and sharp
negative results (no global choice, no global decidability). It is
modeled in simplicial sets and is consistent with — but does not imply
— the axiom of choice for sets and LEM for propositions.

Naming warning (easy to swap): in Rijke's convention the *coercion* is

    equiv-eq : (A = B) → (A ≃ B),   equiv-eq refl := id

and its inverse — the map often called `ua` elsewhere — is

    eq-equiv : (A ≃ B) → (A = B).

Mnemonic: the suffix names the domain, the prefix the codomain. The
univalence axiom asserts that `equiv-eq` is an equivalence.

Dependencies: equivalences, contractibility, fibers (`equivalences.md`);
identity types, transport, `apd` (`identity-types.md`); universes and
the universal family (`universes.md`); the fundamental theorem of
identity types and the structure identity principle
(`fundamental-theorem.md`); propositions, sets, truncation levels
(`truncation-levels.md`); weak funext (`funext.md`); propositional
truncation (`logic-truncation.md`); `Fin k` (`finite-types.md`).

## Key definitions

- **`equiv-eq : (A = B) → (A ≃ B)`**, defined by path induction from
  `equiv-eq refl := id`. Equivalently `equiv-eq p := tr (λX. X) p`:
  transport along `p` in the universal family `λX. X : 𝒰 → 𝒰`.
- **Univalent universe**: `equiv-eq` is an equivalence for all
  `A B : 𝒰`. The axiom: all universes generated by the
  enough-universes rule are univalent. The inverse
  `eq-equiv : (A ≃ B) → (A = B)` is then available. Computation rule
  (propositional): `tr (λX. X) (eq-equiv e) ~ e` — i.e.
  `equiv-eq (eq-equiv e) = e`, and the fiber
  `Σ (p : A = B). equiv-eq p = e` is contractible, so `eq-equiv e` is
  *the unique* identification whose transport realizes `e`.
- **Equivalence induction**: the identity system form of univalence —
  for every `A : 𝒰` and every family `P X e` over `X : 𝒰`,
  `e : A ≃ X`, the evaluation map
  `(Π (X:𝒰). Π (e : A ≃ X). P X e) → P A id`, `f ↦ f A id`, has a
  section. The type-theoretic "WLOG an equivalence is the identity".
- **Smallness**: a type `A` (in any universe) is **𝒰-small** if it
  comes equipped with
  `is-small-𝒰 A := Σ (X:𝒰). A ≃ X`. A map `f : A → B` is **𝒰-small**
  if every fiber `fib f b` is 𝒰-small. Examples: every `X : 𝒰`; every
  contractible type (w.r.t. any 𝒰); `Π (x:A). B x` for 𝒰-small `A`,
  `B`; every finite type (w.r.t. any 𝒰). The type of 𝒰-small types in
  𝒱 is equivalent to the type of 𝒱-small types in 𝒰. (𝒰 itself is
  *not* 𝒰-small — Russell's paradox, later chapter.)
- **Subuniverse**: a family of propositions `P : 𝒰 → Prop-𝒰`, packaged
  as `𝒰_P := Σ (X:𝒰). P X`. Examples: `Prop-𝒰` (propositions),
  `Set-𝒰` (sets), `𝒰^≤k := Σ (X:𝒰). is-trunc k X`, `𝔽` (finite
  types), `BS_n` (`n`-element types), DProp-𝒰 (decidable
  propositions). Notation: for `A : 𝒰_P` one usually writes `A` also
  for the underlying type `pr₁ A`.
- **`iff-eq : (P = Q) → (P ↔ Q)`**, `iff-eq refl := (id , id)` —
  propositional extensionality asserts this is an equivalence.
- **`DProp-𝒰 := Σ (P : Prop-𝒰). is-decidable P`**, decidable
  propositions, where `is-decidable X := X + ¬ X`.
- **The fiber family**: for `f : X → A`, `fib f : A → 𝒰`,
  `a ↦ Σ (x:X). f x = a`. The object classifier is the map
  `(X , f) ↦ fib f`.
- **Connected component of a universe at `A`**:
  `𝒰_A := Σ (X:𝒰). ‖A ≃ X‖`. Note `𝒰_{Fin n} = BS_n`, and
  `A ≃ B` implies `𝒰_A ≃ 𝒰_B`.
- **Decidable map**: `is-decidable f := Π (b:B). is-decidable (fib f b)`.
  **`A ↪d B`**: decidable embeddings — embeddings that are decidable
  maps.
- **Binomial type**: for `A B : 𝒰`,
  `binom-𝒰 A B := Σ (X : 𝒰_B). X ↪d A`
  (printed in the book as a binomial-coefficient symbol). Decidable
  subtypes of `A` merely equivalent to `B`.
- **Axiom of choice (correct, set-level form)**: for `A : Set-𝒰` and
  `B : A → Set-𝒰`,
  `AC-𝒰 A B := (Π (x:A). ‖B x‖) → ‖Π (x:A). B x‖`.
- **Law of excluded middle (correct, propositional form)**:
  `LEM-𝒰 := Π (P : Prop-𝒰). is-decidable P`.
- **Global choice** (refutable): `Π (A:𝒰). ‖A‖ → A`.
  **Global decidability** (refutable): `Π (X:𝒰). is-decidable X`.

## Key results

- **Theorem (three equivalent forms of univalence).** For a universe
  𝒰, TFAE: (i) `equiv-eq : (A = B) → (A ≃ B)` is an equivalence for
  all `A B : 𝒰` (𝒰 is univalent); (ii) `Σ (B:𝒰). A ≃ B` is
  contractible for each `A` — center `(A , id)`; (iii) equivalence
  induction holds. Proof: an instance of the fundamental theorem of
  identity types (`fundamental-theorem.md`) applied to the family
  `B ↦ (A ≃ B)` with reflexivity element `id : A ≃ A`.
- **Plausibility: type formers are equivalence-invariant.** From
  `e : A ≃ A'` and `f : Π (x:A). B x ≃ B' (e x)` one gets
  `Σ A B ≃ Σ A' B'` and `Π A B ≃ Π A' B'`; from `e : A ≃ A'` also
  `(x = y) ≃ (e x = e y)`. So all constructions *within* a universe
  respect equivalence — univalence just makes equality match.
- **Theorem (`is-small-𝒰 A` is a proposition).** Proof: by the
  "proposition if contractible when inhabited" lemma, assume
  `(X , e) : is-small-𝒰 A`; then composing with `e` gives
  `Σ (Y:𝒰). A ≃ Y  ≃  Σ (Y:𝒰). X ≃ Y`, and the latter is
  contractible by univalence. **Corollary:** for univalent 𝒰 ⊆ 𝒱, the
  universe inclusion `i : 𝒰 → 𝒱` is an embedding, since
  `fib i A ≃ is-small-𝒰 A`.
- **Univalence for subuniverses (proposition).** Let `P` be a family
  of propositions over 𝒰. Then for `A B : Σ (X:𝒰). P X`, the family
  `equiv-eq : (A = B) → (pr₁ A ≃ pr₁ B)` is an equivalence. Proof:
  the composite
  `(A = B) —ap pr₁→ (pr₁ A = pr₁ B) —equiv-eq→ (pr₁ A ≃ pr₁ B)`,
  where `ap pr₁` is an equivalence because `pr₁` of a subtype is an
  embedding. In shorthand: `(A = B) ≃ (A ≃ B)` in any subuniverse.
  Consequence: any subuniverse is closed under equivalence —
  `X ≃ Y` gives `P X → P Y` by transport along `eq-equiv`.
- **PROPOSITIONAL EXTENSIONALITY (theorem).** For propositions
  `P Q : Prop-𝒰`, `iff-eq : (P = Q) → (P ↔ Q)` is an equivalence.
  Proof: `(P = Q) ≃ (P ≃ Q) ≃ (P ↔ Q)`; the last step because for
  propositions an equivalence is just a pair of maps, and `P ≃ Q` is
  already a proposition. **Corollary:** `Prop-𝒰` is a set
  (identifications of propositions are the propositions `P ↔ Q`).
- **Decidable propositions are booleans (corollary).**
  `DProp-𝒰 ≃ bool`. Proof: Σ distributes over `+`:
  `Σ (P : Prop-𝒰). P + ¬ P ≃ (Σ (P : Prop-𝒰). P) + (Σ (Q : Prop-𝒰). ¬ Q)`;
  both summands are contractible, centers `(𝟏 , ⋆)` and `(𝟘 , id)` —
  the contractions use propositional extensionality: a proposition
  with a point equals `𝟏`, a proposition with a refutation equals `𝟘`.
- **Postcomposition with an equivalence (lemma).** For `e : X ≃ Y` and
  any `A`, `e ∘ - : (A → X) → (A → Y)` is an equivalence. Proof *must
  not* use funext (it feeds the funext proof): by equivalence
  induction on `(Y , e)` it reduces to `id ∘ - ≡ id`.
- **UNIVALENCE IMPLIES FUNCTION EXTENSIONALITY (theorem, Voevodsky).**
  Sketch: by "weak funext ⇒ funext" (`funext.md`) it suffices to prove
  weak funext: for `B : A → 𝒰` a family of contractible types,
  `Π (x:A). B x` is contractible.
  1. Each `B x` contractible ⇒ `pr₁ : Σ A B → A` is an equivalence
     (its fibers are the `B x`).
  2. By the postcomp lemma, `pr₁ ∘ - : (A → Σ A B) → (A → A)` is an
     equivalence, so its fibers are contractible — in particular
     `fib (pr₁ ∘ -) id = Σ (f : A → Σ A B). pr₁ ∘ f = id`.
  3. Show `Π (x:A). B x` is a *retract* of that fiber:
     `i f := (λx. (x , f x) , refl)` (well-typed since
     `λx. pr₁ (x , f x) ≡ id` judgmentally) and
     `r (h , p) x := tr B (happly p x) (pr₂ (h x))`.
     Then `r (i f) ≡ f` judgmentally (happly of refl is refl,
     `tr` at refl is the identity, η-rule), so the retraction
     homotopy is `refl`.
  4. A retract of a contractible type is contractible.
  Moral: from here on, funext/happly are **free theorems** — use them
  without scruple.
- **THE OBJECT CLASSIFIER (theorem).** For `A : 𝒰` with 𝒰 univalent,

      (Σ (X:𝒰). X → A)  ≃  (A → 𝒰)

  forward: `(X , f) ↦ fib f`; backward: `B ↦ (Σ A B , pr₁)`.
  Proof: `fib pr₁ a ≃ B a` (canonical), so by funext + ua
  `fib pr₁ = B`. Conversely, to identify `(X , f)` with
  `(Σ (a:A). fib f a , pr₁)` use that in `Σ (X:𝒰). X → A`,

      ((X , f) = (Y , g))  ≃  Σ (e : X ≃ Y). f ~ g ∘ e

  (by the structure identity principle: the displayed total space is
  contractible); the fiber-replacement equivalence
  `X ≃ Σ (a:A). fib f a` over `A` provides the pair.
- **Classifier for subuniverses (theorem).** For any family of types
  `P` over 𝒰 (not necessarily proposition-valued),

      (Σ (X:𝒰). Σ (f : X → A). Π (a:A). P (fib f a))  ≃  (A → 𝒰_P)

  by `(X , f , p) ↦ λa. (fib f a , p a)` — the composite of the
  object classifier with `Σ`-reindexing. Applies to k-types, decidable
  propositions, finite types, inhabited types, and to non-propositional
  `P` such as `is-decidable` or `count`.
- **Subtypes are embeddings (corollary).**
  `(Σ (X:𝒰). X ↪ A) ≃ (A → Prop-𝒰)` via `(X , f) ↦ fib f`.
  Hence two views of a subtype of `A`: a Prop-valued family, or a type
  with an embedding into `A`. Equality of subtypes, two ways:
  - as families: `P = Q` iff `Π (a:A). P a ↔ Q a` (funext + prop.
    ext.) — *same elements*;
  - as embeddings: `(X , f) = (Y , g)` iff `Σ (e : X ≃ Y). f ~ g ∘ e`
    (SIP) — *compatible equivalence of domains*.
  SIP + univalence mechanically yields the "natural" notion of
  sameness for each kind of structure.
- **Pointed 2-element types (proposition).** `Σ (X : BS₂). X` is
  contractible; consequently the canonical evaluation family
  `(Fin 2 = X) → X`, `p ↦ equiv-eq p ⋆`, indexed by `X : BS₂`, is a
  family of equivalences. Proof: `Σ (X : BS₂). Fin 2 ≃ X` is
  contractible by univalence; it remains to show
  `e ↦ e ⋆ : (Fin 2 ≃ X) → X` is an equivalence. `is-equiv` is a
  proposition, so proceed by equivalence induction on a putative
  `α : Fin 2 ≃ X`: reduce to `X ≡ Fin 2`, where
  `f : (Fin 2 ≃ Fin 2) → Fin 2`, `f e := e ⋆`, has inverse
  `g ⋆ := id`, `g (i ⋆) := succ-Fin₂` (the swap).
- **NO SECTION OF THE 2-ELEMENT TYPES (corollary).** There is no
  `Π (X : BS₂). X`. Proof: such a section would transport (via the
  family of equivalences above) to `Π (X : BS₂). Fin 2 = X` — a
  contraction of `BS₂` with center `Fin 2`. But identity types of a
  contractible type are contractible, whereas
  `Fin 2 = Fin 2 ≃ Fin 2`, which is not contractible.
- **NO GLOBAL CHOICE (corollary).** For univalent 𝒰 there is no
  `f : Π (A:𝒰). ‖A‖ → A`. Restrict `f` to `BS₂`; every 2-element
  type is inhabited (from `e : Fin 2 ≃ A`, `η (e 0) : ‖A‖`), yielding
  the forbidden `Π (X : BS₂). X`. The obstruction, concretely: any
  such `f` would, via `apd f` along `eq-equiv succ-Fin₂ : Fin 2 = Fin 2`,
  produce a fixed point of the fixed-point-free swap
  `succ-Fin₂ : Fin 2 ≃ Fin 2`. Uniform choice cannot be invariant
  under automorphisms.
- **No global decidability (theorem).** There is no
  `Π (X:𝒰). is-decidable X`: restrict to `BS₂` and use that an
  inhabited decidable type has a point (`is-decidable X → X` when
  `‖X‖`), again producing `Π (X : BS₂). X`.
- **Consistency discipline.** Choice is an axiom about *sets*
  (`AC-𝒰`: inhabited set family over a set has an inhabited section
  type) and LEM is an axiom about *propositions* (`LEM-𝒰`); both are
  consistent with univalence. Their naive all-type versions are
  *refuted* by univalence. The book assumes neither.
- **Binomial types.** With `binom-𝒰 A B := Σ (X : 𝒰_B). X ↪d A`:
  - Characterization (via the subuniverse classifier):
    `binom-𝒰 A B ≃ Σ (P : A → DProp-𝒰). ‖B ≃ Σ (a:A). P a‖`, and
    using `DProp-𝒰 ≃ bool`,
    `binom-𝒰 A B ≃ Σ (f : A → bool). ‖B ≃ Σ (a:A). f a = true‖`.
    The right side is universe-independent, so one writes `binom A B`.
  - Recursion (lemma): `binom 𝟘 𝟘 ≃ 𝟏`; `binom (A + 𝟏) 𝟘 ≃ 𝟏`;
    `binom 𝟘 (B + 𝟏) ≃ 𝟘`;
    `binom (A + 𝟏) (B + 𝟏) ≃ binom A B + binom A (B + 𝟏)`.
    Ingredients: `𝒰_𝟘` is contractible; `𝟘 ↪d X` is contractible
    (center `ex-falso`); the last law via the bool characterization,
    the universal property of `A + 𝟏`, splitting on the value at the
    new point, and injectivity of `- + 𝟏` on equivalences.
  - Finiteness (theorem): if `A` has `n` elements and `B` has `k`,
    `binom A B` is finite with cardinality "n choose k". Proof: the
    claim is a proposition, so assume `Fin n ≃ A`, `Fin k ≃ B`;
    induct on `n k` using the recursion.
  - Why it works: `((X , f) = (Y , g)) ≃ Σ (e : X ≃ Y). f ~ g ∘ e`,
    so decidable embeddings that differ by a permutation of `B` become
    *identified*; `Aut B` acts freely on `B ↪d A` and `binom A B` is
    its type of orbits — the missing factor `1/k!` relative to the
    naive count of injections.
- **Selected chapter exercises (freely usable).**
  - `Σ (A:𝒰). is-contr A` is contractible.
  - `𝒰^≤k` is a (k+1)-type; `Prop-𝒰` is not a proposition; `Set-𝒰`
    is not a set.
  - The implication `¬(Π (x:A). B x) → Σ (x:A). ¬ B x` can fail
    (family `X ↦ X` over `BS₂`).
  - LEM holds iff every set has decidable equality.
  - `A ≃ Σ (B : A → 𝒰). is-contr (Σ A B)`.
  - `f : A → B` is surjective iff precomposition
    `- ∘ f : (B → C) → (A → C)` is an embedding for every *set* `C`
    (hint: test with `C := Prop-𝒰`).
  - (Escardó) `Id_A : A → (A → 𝒰)`, `x ↦ (y ↦ x = y)`, is an
    embedding.
  - `Σ_A : (A → 𝒰) → 𝒰` is a k-truncated map iff `A` is k-truncated
    (hint: `fib Σ_A X ≃ (X → A)`); `+ : 𝒰 × 𝒰 → 𝒰` is 0-truncated.
  - (Escardó) for a proposition `P`, `Π_P : (P → 𝒰) → 𝒰` is an
    embedding.
  - Binary correspondences: `(A → B) ≃ Σ (R : A → B → 𝒰). is-function R`
    and `(A ≃ B) ≃ Σ R. is-function R × is-function (Rᵒᵖ)`, where
    `is-function R := Π (a:A). is-contr (Σ (b:B). R a b)`.
  - `Σ (X : BS_{k+1}). Fin k ↪ X` is contractible; for a k-element
    `A`, `Σ (X : BS_{k+l}). A ↪ X ≃ BS_l`.
  - `Σ (X : BS_{k+1}). X ≃ BS_k` (delete the point); hence
    `Σ (X:𝔽). X ≃ 𝔽` (pointed finite types = finite types).
  - `Π (X : BS_k). X → X` is contractible for `k ≠ 2`, and
    `≃ Fin 2` for `k = 2`; same for `Π (X : BS_k). X ≃ X`.
  - `binom A 𝟏 ≃ Σ (a:A). is-isolated a ≃ Σ (X:𝒰). (X + 𝟏) ≃ A`;
    more generally `binom A B ≃ Σ (X : 𝒰_B). Σ (Y:𝒰). X + Y ≃ A`.
  - Binomial theorem for types: for finite `X`,
    `(A + B)^X ≃ Σ (k:ℕ). Σ ((Y , i) : binom X (Fin k)). A^Y × B^(X∖Y)`.
  - Retracts of 𝒰-small types are 𝒰-small; if `A × B` is 𝒰-small with
    `A B` inhabited, both are; `Retr-𝒰 X` is finite for finite `X`
    and k-truncated for k-truncated `X`.
  - `Σ (X : 𝒰^≤k). A ↠ X` is k-truncated (one below `𝒰^≤k` itself).
  - For `k ≥ 3`, `Π (X : BS_k). (X + X) ↪ (X × X) + 𝟏` is empty —
    cardinality alone does not decide embeddability uniformly; for
    `k = 2` it is `≃ Fin 8`.

## Reasoning idioms

- **To prove `A = B` in a univalent 𝒰**: build an equivalence
  `e : A ≃ B` (map + two-sided inverse, or contractible fibers, or a
  composite of known equivalences) and take `eq-equiv e : A = B`.
  This is the standard way to *construct* identifications of types.
- **To use `p : A = B`**: coerce it to `equiv-eq p : A ≃ B`, or
  transport: for a family `B : 𝒰 → 𝒰`, `tr B p : B A → B B'`.
  Computing transport along a ua-path: `tr (λX. X) (eq-equiv e) ~ e`
  (propositional, not judgmental) — so `tr (λX. X) (eq-equiv e) x`
  may be replaced by `e x` in any further identification-level
  computation.
- **Equivalence induction — "WLOG the equivalence is the identity."**
  To prove `Π (X:𝒰). Π (e : A ≃ X). P X e`, prove only `P A id`.
  Deploy whenever a goal quantifies over an arbitrary equivalence
  (e.g. the postcomp lemma; the `Fin 2 ≃ X` evaluation map). This is
  path induction one level up.
- **To identify elements of a subuniverse** `Σ (X:𝒰). P X` with `P`
  proposition-valued (`Prop-𝒰`, `Set-𝒰`, `𝒰^≤k`, `BS_n`, 𝔽): prove
  an equivalence of the *underlying types*; the `P`-components are
  propositions and follow by transport. Special cases:
  - Propositions: `P = Q` reduces to `P ↔ Q` — prove both directions
    (propositional extensionality).
  - Decidable propositions: work in `bool` — case analysis on a
    decidable `P` is a case split `P + ¬ P`.
- **To identify structures**: combine ua with the structure identity
  principle (`fundamental-theorem.md`):

      ((X , s) = (Y , t))  ≃  Σ (e : X ≃ Y). transport s = t

  e.g. maps into `A`: `(X , f) = (Y , g)` iff
  `Σ (e : X ≃ Y). f ~ g ∘ e`; subtypes iff they have the same
  elements; (later) groups iff isomorphic (`groups.md`). Never prove
  equality of structures componentwise by hand — exhibit the
  structure-preserving equivalence.
- **Object classifier as a dictionary**: a family `B : A → 𝒰` *is* a
  map `pr₁ : Σ A B → A`; a map `f : X → A` *is* its fiber family.
  Properties transfer: embedding ↔ propositional fibers ↔
  `A → Prop-𝒰`; decidable embedding ↔ `A → DProp-𝒰` ↔ `A → bool`;
  surjection ↔ inhabited fibers. Switch representations freely to
  whichever side has the easier lemma.
- **funext is a theorem now**: to prove `f = g` of functions, exhibit
  a homotopy `f ~ g` and apply `funext` — no separate axiom, and no
  circularity once this chapter is proved (`funext.md`).
- **To refute a uniform principle** `Π (X:𝒰). C X`: instantiate at a
  subuniverse with fixed-point-free automorphisms — canonically `BS₂`.
  Any uniform construction must be invariant under `Aut X`; along
  `eq-equiv e` (e.g. the swap on `Fin 2`), `apd` forces the
  construction to be preserved by `e`, which is often impossible
  (a fixed point of the swap). This kills global choice, global
  decidability, and naive "extract from ‖-‖" principles.
- **Counting over `BS_n`/connected components**: `Σ (X : BS_n). C X`
  behaves like "`C`-structures on `Fin n`, up to permutation". Use
  `Σ (X : BS_{k+1}). X ≃ BS_k` to remove a point, and the binomial
  recursion to compute cardinalities. Identity types compute as
  automorphism counts: `(Fin n = Fin n) ≃ Aut (Fin n)` has `n!`
  elements.
- **Working with smallness**: to show a type is 𝒰-small, exhibit an
  equivalence into 𝒰; since `is-small-𝒰 A` is a proposition, the
  witness never needs coherence. Retracts and (inhabited-factor)
  products of small types are small.

## Pitfalls

- **Univalence is inconsistent with "all types are sets"** (axiom K /
  UIP): `(bool = bool) ≃ (bool ≃ bool)` has exactly two elements
  (`id`, `neg-bool`), so a univalent universe is never a set, and
  `A = B` is generally *not* a proposition — at `B ≡ A` it is
  `Aut A`. Do not apply proposition-level reasoning (uniqueness of
  identifications) inside a universe.
- **ua is data, not magic.** `eq-equiv e` is an identification you
  must compute with: the computation rule
  `tr (λX. X) (eq-equiv e) ~ e` is a *homotopy*, not `≡`. Chains of
  transport across ua-paths must be glued with these homotopies; you
  cannot silently reduce them.
- **Do not swap the directions**: `equiv-eq : (A = B) → (A ≃ B)`
  (coercion, `refl ↦ id`) vs `eq-equiv : (A ≃ B) → (A = B)` (ua).
  Check the type before applying; similarly `iff-eq : (P = Q) → (P ↔ Q)`.
- **The center of `Σ (B:𝒰). A ≃ B` is `(A , id)`** — the identity
  *equivalence*, not `refl`. Mixing up identity types and equivalence
  types here is a type error that looks plausible.
- **Naive choice and naive decidability are false under univalence**:
  `Π (A:𝒰). ‖A‖ → A` and `Π (X:𝒰). is-decidable X` are refutable via
  `BS₂`. Only the restricted forms are safe: AC for set-indexed
  families of sets, LEM for propositions. Never "unwrap" `‖A‖` to `A`
  uniformly.
- **`BS₂` is not contractible and `Π (X : BS₂). X` is empty** — even
  though every `X : BS₂` is inhabited. "Every fiber inhabited" does
  not give a section; that is precisely the choice principle that
  fails.
- **Subuniverse univalence needs `P` proposition-valued.** For
  general `P` (e.g. `is-decidable`, `count`, structure families),
  identifications in `Σ (X:𝒰). P X` carry extra compatibility data —
  use the full SIP, not just an underlying equivalence.
- **Truncation off-by-one**: `Prop-𝒰` is a set, not a proposition;
  `Set-𝒰` is a 1-type, not a set; `𝒰^≤k` is a (k+1)-type. Quote the
  level one higher than the objects.
- **`is-small-𝒰 A` is a proposition only by univalence** — the proof
  goes through contractibility of `Σ (Y:𝒰). X ≃ Y`. Without
  univalence smallness need not be propositional. And 𝒰 is never
  𝒰-small (Russell).
- **Circularity trap**: the proof that univalence implies funext must
  not use funext (the postcomp lemma is proved by equivalence
  induction precisely to avoid this). After the theorem, funext is
  freely available.
- **Binomial types require *decidable* embeddings** `↪d`, not plain
  embeddings; the recursion and the classical cardinality formula rely
  on decidability. The universe annotation `binom-𝒰 A B` may be
  dropped only after passing to the `A → bool` characterization.
- **The object classifier needs `A` in the univalent universe**, and
  its round trips use funext + ua — in a development without those,
  the correspondence is only a recursion, not an equivalence.
