# Scope: sources/selinger-graphical-languages/ — additive to root and parent layers

**Selinger, "A survey of graphical languages for monoidal categories"**

In *New Structures for Physics*, Springer LNP 813 (2011), pp. 289–355. LaTeX source: main
`graphical.tex` (`\input graphical.sty`; `llamp.sty` macros; `graphical.bbl`); ~95 `.eps` string-diagram
figures. A reference guide to the zoo of monoidal-category structures and their string diagrams — the
**dictionary** for the diagrammatic vocabulary the project leans on (string diagrams, braiding,
twist, trace, duality), with each notion's coherence/soundness-and-completeness status flagged.
