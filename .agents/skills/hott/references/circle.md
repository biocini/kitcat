# The circle and synthetic homotopy theory

The circle `S¹` is the first **higher inductive type** (HIT): a type generated not only by point
constructors but by a *path constructor* `loop : base = base`. Everything new about HITs lives in
the induction principle — mapping out requires matching data for the paths, not just the points —
and everything powerful about the circle flows from one construction: the **universal cover**
`ℰ : S¹ → 𝒰`, a family with `ℰ base ≃ ℤ`, defined by circle recursion whose `loop` clause is
supplied by the *univalence axiom*. With `ℰ` in hand, the fundamental theorem of identity types
gives `(base = x) ≃ ℰ x`, hence `Ω S¹ ≃ ℤ`, the circle is a 1-type, and `π₁(S¹) ≅ ℤ` as groups.
This proof (Shulman 2011, published as Licata–Shulman) started synthetic homotopy theory; its
method — the **encode–decode** pattern, presented in this book as the fundamental theorem — is the
reusable payload of the chapter.

Dependencies: `apd`, transport, paths-over (`identity-types.md`); equivalences, 3-for-2, fiberwise
maps (`equivalences.md`); the fundamental theorem and identity systems (`fundamental-theorem.md`);
`ℤ` (`inductive-types.md`, `number-theory.md`); truncation levels (`truncation-levels.md`); groups
(`groups.md`). **Axiom usage:** funext is used for the dependent universal property and all
uniqueness statements; univalence is used to construct `ℰ` (descent data). Flagged at each use.

## Key definitions

- **Higher inductive type (concept).** An ordinary inductive type is freely generated by *point
  constructors*; induction says a dependent map is determined by values at the constructors. A HIT
  adds **path constructors**: constructors whose targets are identity types of (the constructors
  of) the type being defined. Consequences: (i) induction acquires one clause per path constructor,
  a *dependent path* clause; (ii) computation at path constructors holds only *propositionally*
  (up to an identification), never judgmentally; (iii) the generated type is usually not a set —
  its identity types carry the interesting data.
- **The circle** `S¹`: the HIT with `base : S¹` and `loop : base = base`.
- **Dependent action on generators.** For `P` a family over `S¹`:

      dgen-S¹ : (Π (x:S¹). P x) → Σ (u : P base). tr P loop u = u
      dgen-S¹ f := (f base , apd f loop)

  Every section produces such generator data; induction says the data conversely produces a
  section. The component `apd f loop : tr P loop (f base) = f base` is a **dependent path** (path
  over `loop`) from `f base` to `f base` — an identification inside the single fiber `P base`,
  well-typed because transport moves `f base` along `loop` within that same fiber.
- **Induction principle of the circle.** For each family `P` over `S¹`:

      ind-S¹ : (Σ (u : P base). tr P loop u = u) → Π (x:S¹). P x
      comphtpy-S¹ : dgen-S¹ ∘ ind-S¹ ~ id

  Spelled out: to construct `f : Π (x:S¹). P x`, supply (1) `b : P base` — the value at the point
  constructor; (2) a **dependent path from `b` to `b` over `loop`**: an identification
  `tr P loop b = b` in `P base`. Nothing weaker suffices — see Pitfalls.
- **Computation rule, honestly stated.** Identifications `(u , p) = (u' , p')` in
  `Σ (u : P base). tr P loop u = u` correspond to pairs `(α , β)` with `α : u = u'` and `β`
  witnessing the square `ap (tr P loop) α ∙ p' = p ∙ α`. Hence for input `(u , p)`,
  `f := ind-S¹ (u , p)` comes with `α : f base = u` and `β` witnessing
  `ap (tr P loop) α ∙ p = apd f loop ∙ α`. So `f base` and `apd f loop` match the input *up to*
  such a pair — no judgmental computation for the `loop` clause.
- **Recursion principle** (non-dependent special case). To define `f : S¹ → X`, supply `x : X` and
  `l : x = x`. Justification: for the constant family `λ_. X`, path induction yields
  `tr-const X p x : tr (λ_. X) p x = x`, so the dependent-path clause reduces to an ordinary
  self-identification.
- **Free loop** in `X`: an element of `Σ (x:X). x = x`. **Action on generators**:
  `gen-S¹ : (S¹ → X) → Σ (x:X). x = x`, `f ↦ (f base , ap f loop)`.
- **Descent data for the circle**: the type `Σ (X : 𝒰). X ≃ X` — a type with an automorphism. Key
  computation lemma (path induction on `p`): for `P : S¹ → 𝒰`,
  `equiv-eq (ap P p) = tr P p`, where `equiv-eq : (X = Y) → (X ≃ Y)` turns a path in `𝒰` into the
  transporting equivalence. The **descent map** is `desc-S¹ : (S¹ → 𝒰) → Σ (X : 𝒰). X ≃ X`,
  `P ↦ (P base , tr P loop)`.
- **The universal cover** `ℰ := 𝒟(ℤ , succ-ℤ) : S¹ → 𝒰`: the family generated by the descent data
  `(ℤ , succ-ℤ)` — i.e. `ℰ base` is `ℤ` (via `x ↦ x_ℰ : ℤ ≃ ℰ base`) and `ap ℰ loop` is, up to the
  descent identification, `ua(succ-ℤ)`, so transport computes as successor:

      tr ℰ loop (k_ℰ) = (succ-ℤ k)_ℰ          (a commuting square)

  Write `y ↦ y_ℤ : ℰ base → ℤ` for the inverse. Picture: a helix over `S¹`; going once around
  `loop` shifts the sheet by one. **Univalence is essential here**: `ap ℰ loop` must be a
  *specific nontrivial* path `ℤ = ℤ`, and `ua` is the only means of producing identifications in
  `𝒰` from equivalences. Without univalence no family with fiber `ℤ` and nontrivial transport
  along `loop` can be written down, and the computation of `Ω S¹` collapses.
- **Helix segments**: for `k : ℤ`, an identification
  `segment-helix k : (base , k_ℰ) = (base , (succ-ℤ k)_ℰ)` in `Σ (t:S¹). ℰ t` — by the
  `Σ`-identity characterization with first component `loop`, second component the square above.
- **Loop space and fundamental group.** `Ω(A , a) := (a = a)`, a group under `∙`; `π₁(A)` is its
  set-truncation as a group (`groups.md`).
- **H-space structure** on a pointed type `(A , pt)`: `μ : A → (A → A)` with *coherent unit laws*
  `left-unit μ : Π (y:A). μ(pt , y) = y`, `right-unit μ : Π (x:A). μ(x , pt) = x`, and
  `coh-unit μ : left-unit μ pt = right-unit μ pt`. Equivalent repackaging (used below): a family
  of base-point-preserving maps `μ : Π (x:A). Σ (f : A → A). f pt = x` with `μ pt = (id , refl)`;
  plus the transport lemma (path induction on `α`)
  `τ : (Σ (H : f ~ g). p ∙ α = H pt ∙ q) → tr (α , (f , p)) = (g , q)`.

## Key results

- **Dependent universal property of the circle** (theorem; uses funext). For every family `P`
  over `S¹`, `dgen-S¹` is an equivalence:

      (Π (x:S¹). P x) ≃ Σ (y : P base). tr P loop y = y

  Proof idea: `ind-S¹` is a section (that is the induction principle); it remains to show
  `ind-S¹ (dgen-S¹ f) = f`. By **funext** it suffices to give `g x = f x` for all `x`, where
  `g := ind-S¹ (dgen-S¹ f)` — prove this by circle induction with the family `E x := (g x = f x)`.
  The loop clause `tr E loop α = α` (for `α : g base = f base`) reduces, by a path-induction
  characterization of transport in such identity families, to a square relating `apd g loop` and
  `apd f loop` along `α` — exactly the pair `(α , β)` supplied by the computation rule.
- **Uniqueness principle** (corollary). Given `y : P base` and `p : tr P loop y = y`, the type of
  sections `f` equipped with `α : f base = y` and `β` witnessing the compatibility square is
  **contractible**. Dependent maps out of `S¹` are uniquely determined by their generator data.
- **Universal property of the circle** (theorem). For each type `X`,

      gen-S¹ : (S¹ → X) ≃ Σ (x:X). x = x

  — maps out of `S¹` *are* free loops. Proof: a commuting triangle with `dgen-S¹` (for
  `P := λ_. X`) and the bottom map `Σ (x:X). x = x → Σ (x:X). tr (λ_. X) loop x = x` induced
  fiberwise by `l ↦ tr-const X loop x ∙ l`; concatenating with a fixed path is an equivalence, so
  the total map is an equivalence by the fiberwise criterion (`fundamental-theorem.md`); 3-for-2
  concludes. Corollary: for a free loop `(x , l)` in `X`, the type of maps `f : S¹ → X` with
  `α : f base = x` and a square `ap f loop ∙ α = α ∙ l` is contractible.
- **Descent theorem** (uses univalence). `desc-S¹ : (S¹ → 𝒰) ≃ Σ (X : 𝒰). X ≃ X`: families over
  the circle are equivalently types with an automorphism. Proof: a commuting triangle over
  `gen-S¹` whose bottom map `tot (λX. equiv-eq)` is an equivalence by **univalence** and the
  fiberwise theorem; 3-for-2. Consequence: identity types of descent data compute as
  `((X , e) = (X' , e')) ≃ Σ (α : X ≃ X'). e' ∘ α ~ α ∘ e`.
- **Working with descent data** (propositions). Let `A` over `S¹` have descent data `(X , e)` with
  `α : X ≃ A base` and `tr A loop ∘ α ~ α ∘ e`. Then:
  - Identifications across `loop` compute on `X`:
    `(tr A loop (α x) = α y) ≃ (e x = y)` (the total space over `y` is a fiber of the equivalence
    `α`).
  - Sections are fixed points: `(Π (t:S¹). A t) ≃ Σ (x:X). e x = x`.
  - Families of maps out of the cover:
    `(Π (t:S¹). ℰ t → A t) ≃ Σ (h : ℤ → X). h ∘ succ-ℤ ~ e ∘ h`.
- **Universal property of the integers.** For `B` over `ℤ` with `b₀ : B 0` and
  `e : Π (k:ℤ). B k ≃ B (succ-ℤ k)`, the type

      Σ (f : Π (k:ℤ). B k). (f 0 = b₀) × Π (k:ℤ). f (succ-ℤ k) = e k (f k)

  is contractible (existence by `ℤ`-induction with seeds `f(-1) := e₋₁⁻¹ b₀`, `f 0 := b₀`,
  `f 1 := e₀ b₀`; uniqueness by applying existence to the family `f k = f' k`). Hence `ev-0` is an
  equivalence. Slogan: `ℤ` is the *initial type with a point and an automorphism*. Consequences:
  powers `k ↦ p^k : ℤ → (x = x)` from the equivalence `λq. p ∙ q`; degree-`k` maps
  `deg(k) : S¹ → S¹`.
- **The universal cover is an identity system at `base`** (theorem). For every family `A` over
  `S¹`, evaluation `f ↦ f base 0_ℰ : (Π (t:S¹). ℰ t → A t) → A base` is an equivalence (a triangle
  of the two equivalences above: maps out of the cover ⟷ `succ-ℤ`-equivariant maps `ℤ → A base` ⟷
  elements of `A base`). Hence, by the uniqueness-of-identity-types criterion and the fundamental
  theorem (`fundamental-theorem.md`):

      (base = x) ≃ ℰ x   for all x : S¹,        Σ (t:S¹). ℰ t   is contractible.

  Direct contractibility proof (exercise): center `(base , 0_ℰ)`; contraction from
  `h : Π (k:ℤ). (base , 0_ℰ) = (base , k_ℰ)` with `h (succ-ℤ k) = h k ∙ segment-helix k`, built by
  `ℤ`-elimination.
- **Loop space and truncation level** (corollary). `Ω S¹ := (base = base) ≃ ℰ base ≃ ℤ`. The
  circle is a **1-type**: by connectedness (`Π (x:S¹). ‖base = x‖`, an exercise) it suffices that
  `Ω S¹` is a set, and `ℤ` is a set. It is **not a 0-type**: `ℤ` is a set but not a proposition
  (`0 ≠ 1`). In particular `loop ≠ refl` — the first provably nontrivial identity type; axiom K
  fails for `S¹`.
- **The fundamental group** (theorem). `π₁(S¹) ≅ ℤ` as groups. Two ingredients:
  - *Augmented fundamental theorem* (proposition): if `B` is an identity system at `a` with
    `b : B a` and `μ : B a → (B x → B x)` satisfies `μ(- , b) ~ id`, then the canonical family
    `f : Π (x:A). (a = x) → B x` with `f refl = b` satisfies `f (p ∙ q) = μ (f p) (f q)` for
    `p : a = a`, `q : a = x` (based path induction on `q`).
  - The operation on the cover: `μ(k_ℰ , l_ℰ) := (k + l)_ℰ` exists by the descent-data
    computation of maps out of the cover, since `k + (l + 1) = (k + l) + 1` says `l ↦ k + l` is
    `succ-ℤ`-equivariant.

  So `α : Π (t:S¹). (base = t) → ℰ t`, `α refl := 0_ℰ`, satisfies
  `α(p ∙ q)_ℤ = α(p)_ℤ + α(q)_ℤ`: a group isomorphism `Ω S¹ ≅ ℤ`. Since `S¹` is a 1-type, `Ω S¹`
  is already a set, so `π₁(S¹) ≅ Ω S¹ ≅ ℤ`.
- **H-space structure on the circle** (construction). There is `mul-S¹ : S¹ → (S¹ → S¹)` with
  coherent unit laws `left-unit-S¹`, `right-unit-S¹`, `coh-unit-S¹`. Highlights: use the
  repackaged data `μ : Π (x:S¹). Σ (f : S¹ → S¹). f base = x` with `μ base = (id , refl)`; the
  `loop` clause then demands a dependent path in `P base := Σ (f : S¹ → S¹). f base = base` from
  `tr P loop (id , refl)` to `(id , refl)`, which via `τ` reduces to a homotopy `H : id ~ id` with
  `loop = H base ∙ refl`. Such an `htpy-id-S¹` is defined by the dependent universal property with
  the family `E x := (x = x)`, using `htpy-id-S¹ base := loop` and `γ : tr E loop loop = loop`
  obtained from `refl (loop ∙ loop)` via `(p ∙ r = q ∙ p) → (tr E p q = r)`. Characterization:
  `mul-S¹` is the unique map with `base-mul : mul-S¹ base = id` and `ap mul-S¹ loop` matching
  `eq-htpy htpy-id-S¹` (uses funext). Exercises: each `mul-S¹ (x , -)` and `mul-S¹ (- , x)` is an
  equivalence; `mul-S¹` is an embedding; associativity, commutativity, and inverses `inv-S¹` make
  `S¹` an abelian group up to homotopy; the Mac Lane pentagon and all higher coherences hold
  *automatically* because `S¹` is a 1-type.
- **Selected consequences and exercise results.** `S¹` is connected: `Π (x:S¹). ‖base = x‖`; but
  `¬ Π (x:S¹). base = x` (the cover obstructs it), hence `¬ Π (X : 𝒰). ‖X‖ → X`: propositional
  truncation does not split. A type `X` is a set iff `const : X → (S¹ → X)` is an equivalence, iff
  `ev-base : (S¹ → X) → X` is. Pointed maps: `(Σ (f : S¹ → X). f base = x) ≃ (x = x)`; pointed
  self-maps of `S¹` are counted by `ℤ` (degree); pointed self-equivalences by `bool`;
  `(S¹ ≃ S¹) ≃ S¹ + S¹`, so a univalent universe containing `S¹` is not a 1-type. The twisted
  double cover `𝒟(bool , neg-bool)` has total space equivalent to `S¹` over the degree-2 map.

## Reasoning idioms

### Idiom 1: defining maps and sections out of `S¹`

- **Recursion** — to get `f : S¹ → X`: supply `x : X` and `l : x = x`.
- **Induction** — to get `f : Π (t:S¹). P t`: supply `b : P base` and a dependent path
  `q : tr P loop b = b`. Then:
  - Compute `tr P loop b` with transport algebra until the goal is between concrete elements of
    `P base`: `tr-const` for constant families; transport in `Σ`/`Π`/identity families;
    `equiv-eq (ap P loop) = tr P loop` for `𝒰`-valued families.
  - Expect only *propositional* computation: `f base` and `apd f loop` match the inputs via
    `(α , β)`. To identify two maps out of `S¹`, don't rewrite — compare generator data
    `(f base , ap f loop)` and invoke the uniqueness corollary.
  - Prefer the universal properties over raw induction: generator data ⟹ unique map ⟹
    contractible space of such maps with compatibility identifications.

### Idiom 2: the encode–decode recipe — identity types of a HIT

To characterize `(a = x) ≃ ℰ x` for a HIT with a chosen point `a`:

1. **Define the codes family** `ℰ : HIT → 𝒰` by the HIT's recursion: point constructors ↦ concrete
   code types (here `base ↦ ℤ`); path constructors ↦ `ua(e)` for a constructed auto-equivalence
   `e` (here `succ-ℤ`). *Univalence enters exactly here* — it is the only source of nontrivial
   paths in `𝒰`. Bundle the result as descent data so transport along each path constructor
   computes as `e`.
2. **Exhibit the reflexivity code** `b : ℰ a` (here `0_ℰ`). Based path induction gives the
   **encode** map `encode x p := tr ℰ p b : (a = x) → ℰ x` with `encode a (refl a) ≡ b`
   judgmentally. (`encode base loop = 1`: the winding number.)
3. **Prove the total space contractible**: `Σ (x:HIT). ℰ x`, center `(a , b)`. This is the
   mathematical work — do it by the HIT's induction, using the code type's own elimination
   principle (here: helix segments + `ℤ`-elimination).
4. **Apply the fundamental theorem**: `encode` is a fiberwise equivalence, `(a = x) ≃ ℰ x`; the
   inverse is **decode**, and both round-trip homotopies come for free.
5. **Harvest**: set `x := a` for the loop space; if codes are `k`-types and the HIT is connected,
   the HIT is `(k+1)`-truncated; equip codes with an operation to read off the group structure.

Pre-flight checklist: the family is defined over the *whole* HIT (every path constructor gets an
*equivalence*, not just a map); the base point is fixed; the goal is total-space contractibility,
never fiberwise.

### Idiom 3: descent data — work on the base, transport to the circle

Present `A : S¹ → 𝒰` by `(X , e)` with `α : X ≃ A base` and `tr A loop ∘ α ~ α ∘ e`. Then move
every problem to `X`: sections are fixed points of `e`; maps of families are equivariant maps;
identifications across `loop` are identifications in `X`. Solve on `X` (e.g. `ℤ`, where induction
is ordinary) and transport back along `α`.

### Idiom 4: elimination over `ℤ` with an automorphism

To build `f : Π (k:ℤ). B k` from `b₀ : B 0` and `e : Π (k:ℤ). B k ≃ B (succ-ℤ k)`: `ℤ`-induction
with the three seeds and step maps `λn. e⁻¹` (negative), `λn. e` (positive). The result is unique —
`ℤ` is initial among pointed types with an automorphism. Reach for this whenever a construction
"by winding" appears: powers `p^k`, helix contractions, degree maps.

### Idiom 5: upgrading a loop-space equivalence to a group isomorphism

An equivalence `Ω A ≃ G` of types says nothing about `∙` versus the operation on `G`. Exhibit the
operation `μ` on codes with `μ(- , b) ~ id` (usually read off descent data, as addition was from
`k + (l + 1) = (k + l) + 1`); the augmented fundamental theorem then gives
`f (p ∙ q) = μ (f p) (f q)` by based path induction on `q`. Check truncation: if `A` is a 1-type,
`π₁(A) = Ω A` with no set-truncation needed.

### Idiom 6: canonical maps via commuting triangles and 3-for-2

Universal properties of HITs are proved by factoring the canonical map (`dgen-S¹`, `gen-S¹`,
`desc-S¹`) through known equivalences: fiberwise-equivalence criteria for `tot`, univalence's
`equiv-eq`, previously established universal properties. Deploy them backwards: from generator
data, obtain the unique map *and* the contractibility of its compatibility data.

## Pitfalls

- **Dropping the dependent-path clause.** `b : P base` alone does not yield a section of `P`. The
  clause `tr P loop b = b` is required, and it is an identification *in the fiber `P base`* —
  always state it through transport, never as `b = b` "over `loop`".
- **Ill-typed loop clauses in general.** For dependent `f : Π (x:A). P x` and `p : x = y`,
  `f x = f y` is not a type; transport first: `apd f p : tr P p (f x) = f y`. The circle's clause
  looks like a self-identification only because `loop` is a self-loop.
- **Assuming judgmental computation for `loop`.** The computation rule is the homotopy
  `dgen-S¹ ∘ ind-S¹ ~ id`, unpacked as `(α , β)`. Never rewrite `apd (ind-S¹ (u , p)) loop` to `p`
  judgmentally; use uniqueness to identify maps.
- **Trying to prove `loop ≠ refl` by path induction.** Path induction needs a free endpoint;
  `loop : base = base` has none. Nontriviality is proved *through the cover*: `(base = base) ≃ ℤ`
  and `0 ≠ 1` in `ℤ`. Likewise never assume `loop = refl` — axiom K fails for `S¹`.
- **Forgetting why univalence is load-bearing.** `ℰ` is nontrivial only because
  `ap ℰ loop := ua(succ-ℤ)` makes `tr ℰ loop = succ-ℤ ≠ id`. Without univalence there is no way to
  supply the `loop` clause of a `𝒰`-valued recursion with anything but trivial transport, and the
  encode–decode argument cannot start.
- **Fiberwise versus total space.** Contractibility is asserted of `Σ (t:S¹). ℰ t` (the helix),
  never of the fibers `ℰ t ≃ ℤ` — those are inhabited but far from contractible. Sanity check: the
  center is `(base , 0_ℰ)`.
- **Direction of transport.** `tr ℰ loop k = k + 1` and `tr ℰ loop⁻¹ k = k − 1` (predecessor). A
  sign slip turns the winding number into its negative and breaks the group isomorphism.
- **Claiming `π₁` from a bare type equivalence.** `Ω S¹ ≃ ℤ` becomes a *group* isomorphism only
  after checking the operation (Idiom 5). And `π₁` is set-truncated in general; the truncation
  disappears here only because `S¹` is a 1-type.
- **Truncation-level slippage.** `ℤ` is a set; `ℰ` is set-valued; `S¹` is a proper 1-type.
  "1-type" means identity types are *sets* — loop spaces of `S¹` are sets, and their identity
  types are propositions. Do not assert `S¹` is a set (false), and do not assert a univalent
  universe containing `S¹` is a 1-type (false: `(S¹ ≃ S¹) ≃ S¹ + S¹`).
- **Over-using connectedness.** `Π (x:S¹). ‖base = x‖` is truncated; it does not yield
  `Π (x:S¹). base = x` — the cover obstructs exactly this. Connectedness justifies reducing "all
  identity types are sets" to "`Ω S¹` is a set", nothing more.
- **Missing the H-space coherence.** `left-unit` and `right-unit` must agree at `base`
  (`coh-unit`). A noncoherent structure can be adjusted to a coherent one (exercise), but the
  construction delivers the coherent one directly via `μ base = (id , refl)`.
