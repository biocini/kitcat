# Toolchain Block — Contract and Examples

Euler workflows are proof-assistant-agnostic. They never invent a build or
check command. Instead, every fact about *how this project talks to its kernel*
lives in one place: the **toolchain block**.

The host project MUST provide it, either as:

- a `TOOLCHAIN.md` file at the project root, or
- a `## Toolchain` section inside the project's `AGENTS.md`.

If a workflow cannot find a toolchain block, it stops and asks the user for the
check command, the sorry token, and the library layout before doing anything
else. It records the answers as the resolved toolchain block for the run. It
never guesses: an Agda `postulate`, a Coq `Axiom`, and a Lean `sorry` are not
interchangeable, and a wrong check command is worse than none.

## Fields

| Field | Required | Meaning |
|---|---|---|
| `check` | yes | Command that type-checks the whole project (the oracle). |
| `check-file` | yes | Command pattern to check one file, with `{file}` placeholder. |
| `sorry-token` | yes | grep-able token(s) marking incomplete proofs/obligations. |
| `unsafe-markers` | yes | Tokens/flags that weaken kernel guarantees in this project. |
| `lib-layout` | yes | Where library modules live; module naming conventions. |
| `clean-build` | no | Command for a from-scratch build (deliverability check). |
| `probe` | no | Cheap environment check, e.g. version command. |
| `search-dirs` | no | Directories to search when locating declarations. |

Semantics the workflows rely on:

- **The check command is the oracle.** A proof is `verified` only when a
  recorded run of `check` (or `check-file`) succeeded. Exit status and output
  are what count — never an agent's judgment.
- **Sorry tokens are obligations.** A grep hit in a delivered file is an open
  obligation, full stop. Workflows report the obligation count from grep, not
  from memory.
- **Unsafe markers downgrade claims.** Any hit in a delivered file must be
  disclosed in the artifact's provenance sidecar; claims of "complete" or
  "fully checked" are false while unaccounted hits exist.

## Example blocks (do not copy blindly — measure your own project)

### Agda

```markdown
## Toolchain
- check: `agda --safe --no-libraries Everything.agda`
- check-file: `agda --safe --no-libraries {file}`
- sorry-token: `postulate`, `{!!}`
- unsafe-markers: `--no-guardedness`, `--no-positivity-check`, `TERMINATING`, `NON_TERMINATING`, `--allow-unsolved-metas`, `{-# OPTIONS --safe #-}` absent
- lib-layout: modules under `src/`, hierarchical names mirroring paths (`src/Data/Foo.agda` -> `Data.Foo`); index file `Everything.agda` imports all public modules
- clean-build: `rm -rf _build && agda --safe --no-libraries Everything.agda`
- probe: `agda --version`
- search-dirs: `src/`
```

### Lean 4

```markdown
## Toolchain
- check: `lake build`
- check-file: `lake env lean {file}`
- sorry-token: `sorry`, `admit`
- unsafe-markers: `axiom`, `unsafe`, `partial`, `noncomputable` (if the project disallows it), `set_option ... in` weakening checks
- lib-layout: modules under `LibName/`, one declaration-namespace per directory; `LibName.lean` root import file
- clean-build: `lake clean && lake build`
- probe: `lake --version`
- search-dirs: `LibName/`
```

### Rocq / Coq

```markdown
## Toolchain
- check: `make -j4` (or `dune build`)
- check-file: `coqc {file}`
- sorry-token: `Admitted`, `admit`
- unsafe-markers: `Axiom`, `Parameter` (unproved), `Admitted`, `-allow-rewrite-rules`
- lib-layout: theories under `theories/`, `Makefile` generated by coq_makefile
- probe: `coqc --version`
- search-dirs: `theories/`
```

### Isabelle/HOL

```markdown
## Toolchain
- check: `isabelle build -D .`
- check-file: `isabelle process -l HOL -e 'use_thy "{file}"'` (project-specific)
- sorry-token: `sorry`, `oops`
- unsafe-markers: `axiomatization`, `oracle`, `skip_proof`
- lib-layout: theories under `thy/`, `ROOT` file declares sessions
- probe: `isabelle version`
- search-dirs: `thy/`
```

## Resolution log line

Every workflow logs the resolved block once per run, e.g.:

```
[toolchain] check='agda --safe --no-libraries Everything.agda' sorry='postulate,{!!}' lib=src/
```
